# 设计参考

当前状态：**优先与用户确认设计方向，之后再开发客户端。** 产品要有设计感和品位，同时让人像逛手机淘宝、小红书一样发现有意思的 Prompt。

| 路径 | 状态 |
|---|---|
| `v2/` | 历史 10 屏 HTML 静态稿，仅作参考；非当前首版范围或最终设计 |
| `v2/assets/` | 示意插画，不代表真实内容 |

旧稿的图片／视频／Skill 组织、暗色亮绿配色和固定十屏已经不能代表当前方案。首版覆盖文本、图片、视频、网页，Skill 后置；需要用同一组四类内容比较新的设计方向，并由用户确认。

HTML 用于展示设计，不用于实现 App。iOS 和后续 Android 均采用原生实现。当前要求见 [设计规范](../docs/design.md)，范围见 [产品定义](../docs/product.md)。

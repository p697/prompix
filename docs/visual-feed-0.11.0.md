# 0.11.0（42）：视觉优先的信息流与供给

2026年10月16日现场排查：745条内容中有269条图片、61条视频、7条网页；严格最新排序的前22条却全部是无图文字（19条Prompt、3条Skill），最近的图片在第23位。最新一次发布的类型集中，使新用户连续几屏只能看到文字。库中有视觉内容，按发布批次直接堆叠不适合当前移动端产品方向。

## 首页

默认“全部内容”使用服务端 `sort=discovery`。存在两类候选时，每5条先安排4条真实视觉预览，再安排1条无图文字；各类内部使用已有首次发布顺序。图片、视频、网页和有合法真实来源封面的Skill都能进入视觉类；写着“图片/视频”的标题或标签不会取得视觉资格。某一类耗尽时继续展示另一类，不删掉内容或降低结果总数。

筛选菜单保留“最新收录”，用户可明确选择严格时间顺序；类型Tab仍按最新排列，搜索仍按相关性排列。推荐默认会把较早但仍近期的视觉内容放在最新文本之前，这一决定取代0.8.1默认严格最新的选择。

分页游标分别记录两类的latest_position和下一个混排位置，并签名绑定条件、发布快照和24小时期限。翻页不依赖OFFSET、即时row_number或者客户端当前一页重排；换每页大小、发布新版本或下架内容不会重编号已发出的游标。每次只从每类最多读取limit+1张轻量卡片，最终响应仍不超过现有每页/字节限制。旧sort和旧游标保持兼容，没有修改数据库权限、表结构或RLS。

用途封面去重沿用当前首页查询，推荐与最新两种模式都避开开头内容；加载骨架和实际卡片继续共享既有尺寸。新增排序有独立缓存身份，离线时不会将旧的最新页冒充推荐页。

## 采集、审核与发布

- X的10个搜索位置中8个面向带图片或视频的作品，另1个面向创意Skill发现、1个面向文字。覆盖人像/时尚、产品摄影、插画/海报、拼贴/电影感、短视频/动画及网页预览；保持原先12请求/600帖的本机配置，不扩大付费总预算。回复补抓继续共享原额度，搜索主题比例不等于每天实际抓到的类型比例。
- 编辑审核调度将80%的轮换位置给视觉候选，优先X；维护和创意文字各10%。已有内容修正继续保留维护能力。当天新无图文字最多尝试审核20条，包括此前持久化的尝试，避免大量文字库存耗光付费审核预算。候选不足时可让出排序位置，但不能绕过文字尝试上限或质量门禁。
- 所有许可、原文完整性、视觉一致性、翻译和可用性门禁照常执行。通过门禁后优先选择视觉新增；每天新增硬上限仍为100。纯文字最多10条/UTC日、最多占当天新增20%，并随原有四个时段累计释放额度。4条已发布或本轮可发布的视觉作品才允许1条文字；视觉不足时文字继续等候，不为凑数量放行。既有内容及其修订不占新的首次发布额度，也不批量下架现有文字收藏。
- 比例选择由受全局内容锁保护的日常发布管线执行；数据库激活仍独立锁定并重检100条硬上限。比例选择不是新的数据库约束，手工绕过标准管线的发布操作不自动受它管理。历史超额文字不删除、不退还额度，新规则会先让视觉新增补足比例。

收录目标仍为质量达标后的每日50–100条，不保证每天凑足。Skill缺少授权封面时保留文字呈现，不能伪造生成效果或复制平台专属内容。

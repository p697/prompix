# Prompix：暗房 · 白

2026-11-06，Prompix 2.0 设计语言第一步。用户在五个版本和暗房红／白／蓝重做之后选定「暗房 · 白」，取代 0.12 起的蓝紫光谱和更早的绿色主题。完整设计稿与逐页功能说明在 2.0 设计画布（「暗房 · 白：详细设计」与「页面与功能说明」两组）；页面结构按稿子分步还原，本文件记录已经落进代码的部分。

## 原则

作品是屏幕上唯一的颜色。界面只有黑、灰、白：主按钮、选中态、可以填的空都用白色（浅色模式里反过来用黑色）。照片、视频和 Prompt 正文保持原色，不给文字、图标或控件套渐变。Liquid Glass 只用在导航栏、Tab 栏、底部操作栏和浮层，交互、高亮和菜单由系统实现。

## 配色契约

统一从 `Views/Theme.swift` 的 `Palette` 取色，不在业务页面重新定义主题色。深色是「暗房」，浅色是「相纸」，默认跟随系统。

| 角色 | 浅色（相纸） | 深色（暗房） | 用途 |
|---|---|---|---|
| paper | `#F4F3EF` | `#0B0B0C` | 页面底色 |
| surface | `#FBFAF7` | `#18181A` | 灯箱面板、文本卡 |
| soft | `#E8E7E2` | `#1E1E20` | 骨架、Skill 卡与低强调区域 |
| ink | `#141415` | `#F5F5F2` | 正文、标题 |
| muted | `#6B6B67` | `#9A9A97` | 辅助文字、开关打开时的轨道 |
| accent | 同 ink | 同 ink | 主操作、选中态、链接 |
| line | `#DAD9D3` | `#2A2A2C` | 分隔线 |

主按钮是 accent 底、paper 字：深色里白底黑字，浅色里黑底白字。Liquid Glass 的 tint 用 `Palette.glassAccent(for:)` 按页面外观直接取值，避免交互式 zoom 期间材质快照带来临时的 UIKit trait。系统开关在白色 tint 下会看不见滑块，所以开关用 muted 作 tint；`.borderedProminent` 按钮显式使用 paper 字色。

## 品牌

App Icon 是黑底三张白色卡片：左卡 28%、右卡 50%、中间前卡不透明并带一圈淡光，深色和默认外观使用同一张，tinted 外观使用灰度版本。`SpectralPages` 的紧凑标记沿用这组卡片的透明度和前后关系；首次引导的七张卡片用同一套透明度，以 ink 绘制，浅色模式里随之变成黑色卡片。轻翻页 `PageActivity` 的三个页片用 ink，透明度随抬升变化。

## 字体与信息流

界面用 SF Pro；Prompt 文字用 New York（`Typography.prompt`）；类型、模型、比例、编号这类参数用 SF Mono（`Typography.meta`），像底片边上的印字，例如「文本 ▸ CLAUDE」。

信息流卡片只有作品本身，不带标题和徽章；标题只作为无障碍标签。瀑布流的每张卡片高度在绘制前就已算定（作品比例、文本卡估算），每列是按精确高度排好的普通栈，只在视口上下一屏内构建卡片；不用惰性列表的估算高度，所以滚动时网格总高度不变，阅读位置以上的内容永远不会移动。卡片 12pt 连续圆角，列间距和行间距都是 6pt，左右边距 16pt，卡片高度就是预览高度。文本卡和 Skill 卡见下方「文本卡」。视频只在左下角放一个小的播放标记；时长字段到位后再显示时长，不显示假时长。

发现页页头是「发现」大标题和右侧一个玻璃筛选按钮（只有模型；有筛选时右上角一个小圆点）。大标题下面是横向滚动的用途标签：「全部」、作品最多的九个用途，最后是「更多 ⌄」，点开是半屏的「全部分类」，三列胶囊列出所有用途；从那里选中的用途会接在九个后面显示。用途名是 App 自己的短名，中文两到三个字（人像、穿搭、短片、插画……），其他语言大多一个词，由 `use.<id>` 字符串提供，服务器新增的用途先用 `facets.json` 的名字。选中的标签是实心胶囊（accent 底、paper 字），其余是灰色文字。信息流上方一行「为你挑的」，右侧两个等宽菜单：「类型 ▾」选全部／图片／视频／文本（选中后显示类型名并加深），「推荐 ▾」切换推荐／最新；类型和排序只在这里，不在筛选里重复。换用途保留类型，换类型保留用途、清掉模型。搜索页仍用图片／视频／文本标签。设置入口只在收藏页页头。创作者和按用途两条横向栏放在信息流第 12 张作品之后，首屏只有作品；筛选时不出现。

详情页只突出三样东西：作品、模型和 Prompt 原文。大图通栏铺满宽度、从状态栏下开始，按作品自己的比例显示，底部 28pt 缓入渐隐进页面底色；只有比 2:3 更高的图从底部裁掉一些，每一张都从顶部对齐，脸和主体始终完整，点开看完整原图。图上只有和首页同一道状态栏磨砂（`EdgeVeil`）：三层超薄材质在不同深度淡出，越靠顶越模糊，只带一点点纸色，没有分界线；全 App 的顶部阴影都只有这一点，系统顶部模糊关闭，不压住作品。多张图直接左右滑动，右下角是「1 / 3」页码，点开全屏停在当前这张。大图下面是一行等宽参数「模型 ▸ 比例 ▸ 时长」，模型名加深；模型不明确时直接省略，文本、网页和 Skill 不写比例。标题 24pt semibold。标题下直接是「PROMPT」和原文，右侧一个小的语言切换；原文默认显示约七行，末尾渐隐加「展开全文」；有分镜的视频只显示分镜，不重复正文。往下滑过标题后，导航栏后面换成纸色渐变，标题缩成 15pt 居中显示在两侧按钮之间；底栏后面也有一层向上渐隐的纸色（只高出按钮 16pt，最深 82%，正文能透出来），正文不会压在按钮下。最下面一行灰色的「更多信息」默认收起，展开后依次是创作者、语言、原帖、许可、发布日期，每行 44pt 高，最后是「报告问题或申请下架」：直接写一封发往 support@prompix.dev 的邮件，标题带上这条内容的编号，正文预填标题和编号，不带任何读者信息；收到后 24 小时内处理。再往下是「相关」：同用途（没有就同类型）的六个作品，网格与其他页面一样左右 16pt，没有内容时整段不显示。

详情页底栏只有两个按钮：铅笔「写我的版本」和主按钮「复制 Prompt」。不再有「复制并打开某个工具」和使用托盘：跳转到网页并不能带上内容，用户还是要自己粘贴。用户可以基于任何 Prompt 写自己的版本：编辑时自动保存，第一次改动就生成一个新版本；详情页 PROMPT 下方出现「原版 / 我的 1 / 我的 2 / ＋」切换，版本按创建先后排列，「＋」以当前显示的文字新建一个版本；复制和再编辑都针对当前选中的版本。PROMPT 这一行固定 44pt 高：原版时右侧是语言菜单，选中自己的版本时换成「⋯」菜单（重命名、删除这个版本），切换时正文不跳动。重命名后芯片显示新名字，清空名字就回到编号。编辑器标题是版本名，右上角只有复制。收藏页「我的版本」列出写过版本的作品。

收藏页顶部是「卡组 / 创作者 / 我的版本」分段控件，右上是设置和新建卡组两个按钮。卡组存在独立的 `decks.json`，与收藏文件分开，文件损坏时只读不覆盖；「全部收藏」不是卡组，而是所有收藏。卡组页始终是两列卡组格子：第一格「全部收藏」，然后是自建卡组，最后一格是虚线的「新建卡组」；封面是 2×2 拼图，圆角 16。一件都没收藏时显示六个空白底片格和一句说明。详情页书签在没有自建卡组时仍是一点即收藏；有卡组时弹出「收藏到」半屏面板，「全部收藏」始终勾选，取消收藏也在面板里。取消收藏会把作品从所有卡组移除。卡组内页顶部是等宽参数行「卡组 ▸ N 张」和标题，有两种以上类型时显示类型切换，下面是三列等大方格，间距 4，像一张印样。

搜索首页只有「最近」（可横滑的灰色胶囊）和「按用途」四张照片格子，格子底部用渐变压暗托住白字，封面优先用服务端浏览接口的封面。说明文字、搜索页右上的「更新内容」按钮和首页的创作者横条都去掉了：更新靠下拉刷新和设置，创作者出现在搜索结果里。「用一张图找」「榜单」「大家在搜」「按颜色」等服务端就绪后再加。

长按任何作品卡片，预览是作品大图、参数行、标题和 Prompt 前三行（信息流卡片在详情未下载时显示摘要）；菜单依次是复制、收藏、少推荐这类。

创作者页：名字用粗体大标题，账号和条数用等宽小字；「收藏创作者」是唯一的主按钮（白底），「查看主页」是旁边的灰色胶囊，右上只留分享。

发现页筛选按钮联网时提供三组 2.0 筛选：用途（`packages/schema/facets.json` 的名称、按服务端计数排序）、模型族（不提供「其他」，因为它大多是原文未注明模型）和参考图（不需要上传／可以用我的照片／需要上传）。离线或服务端没有计数时退回原来的用途和模型菜单。

## 动态语法

| 场景 | 当前组件与行为 |
|---|---|
| 第一页尚无内容 | 所有卡片一致的原比例静态骨架，不叠加任何 Loading 图形 |
| 正文尚未到达 | 先呈现封面、标题和已有操作区；正文仅文字骨架 |
| 作者目录等待 | 头像／姓名同尺寸骨架；已知作品保持可用，不附加加载图 |
| 下拉刷新 | 保留系统 UIRefreshControl 的手势、回弹与生命周期；可见反馈为轻翻页 |
| 加载下一页 | 局部轻翻页，不显示重复的“正在加载”文字 |
| 图片、视频、网页、语言包 | 应用自己的等待统一轻翻页；已有媒体预览不清空 |
| 请求失败 | 移除加载图形，保留短说明与原生玻璃重试 |
| 减少动态效果／低电量 | 静止页片，保留 VoiceOver 状态描述 |
| 详情底栏 | 保留编辑／复制／使用的布局与下滑收起；正文滚动视图使用系统 soft 底部边缘效果，让正文在按钮下方淡出，不另叠材质 |
| 首页、收藏页头 | 大标题和分类 Tab（收藏页是分段控件）用 `safeAreaBar` 固定在顶部，往下滚整块收起，往上滚展开，弹簧与详情底栏相同。收起只移动页头本身，内边距不变，内容位置不动。展开时页头后面是纸色和轻模糊，内容滚到下面后再向下渐隐 12pt，让 Tab 在图片上也看得清；收起后参照 Cosmos，只在状态栏后面留一层很浅的纸色和模糊，过了状态栏 10pt 就消失，作品在时间下面仍隐约可见，屏幕几乎全留给内容。系统顶部边缘效果关闭。iOS 26 起 Tab 栏下滑缩小 |
| 卡片按压 | 作品卡、专题卡、创作者卡按下缩到 0.97，弹簧 0.22／0.78；减少动态效果时改为变淡。系统玻璃、菜单和选择器保留各自的原生反馈 |
| 触感 | 只在切换分类、复制成功、收藏成功时给，滚动和按压不震 |

`PageActivity` 是三个 8pt × 14–17pt 页片，相邻错开约 0.3 秒，周期 1.8 秒，最大抬升 3pt。固定 28pt 高的区域，30fps 上限。无球体、圆环、轨道、弹跳或全屏装饰。请求结束不等动画演完；离屏、后台、减少动态效果和低电量停止更新。不要为视觉效果设置最短请求时长或伪造进度。

`LoadingSurface` 是一致的静态占位。不要在第一张卡片、创作者骨架头部或正文骨架加页片。对于有骨架的区域，骨架本身就是等待反馈。

`pageRefreshable` 复用系统刷新任务，仅通过公开 UIView／UIRefreshControl 属性替换可见样式：原生控件 tint 透明，附加局部 SwiftUI 页片。禁止替换滚动 delegate、使用私有类名或另加竞争手势。若当前系统视图结构不提供唯一可定位的刷新控件，保留系统反馈作为安全回退。AVKit 内部系统控件不是应用自定义 UI；不通过私有接口篡改它们。

## 异常与内容连续性

已有内容优先于错误说明。`ContentRecoveryRow` 不采用居中大卡片、额外白色容器、沉重的灰色胶囊或多段重复文案。标准点击范围至少 44pt；使用原生 `glass` 按钮，旧系统回退到无边框按钮。Retry-After 冷却期仍须遵守，不因视觉简化而绕开限流。

首屏请求失败时：短恢复行后直接显示真正可用的离线内容，不再额外叠加“更新未完成”和“离线可用”两个标题。点重试时保留这批内容，到有效页面返回才替换。分页失败时保留已经载入的卡片，在尾部就近恢复。切换筛选不得把旧查询的结果留在新标题下。

无可用内容的确认空态、内容下架和真正失败必须分别处理。用户需要采取行动或了解数据来源时保留短说明；仅“正在加载”这类不增添信息的可见文字可以省略，VoiceOver 描述保留。

## 后续改动的完成条件

分类切换必须同步交接选中态、对应内容与滚动复位。暖缓存直接显示，不能反复清空成骨架；冷缓存只显示本分类占位，不能临时借用上一个分类卡片。骨架与真实内容共用布局起点，网格测量状态保持稳定，首帧使用容器的准确宽度。大图缓存被淘汰时，可以用有界小缩略图衔接重新解码，不能用无上限图片缓存换取流畅。分类下划线可以有局部动画，整个瀑布流不要随筛选改变做位置插值。发现页采用有上限、完整查询隔离的首屏缓存；具体生命周期见 [0.12.2](filter-transition-0.12.2.md)。

- 实际查看正常、等待、失败、重试、空结果和缓存内容，不只截成功页面。
- 在模拟器验证首页滚动收起、返回途中 Tab 连续性、已有媒体立即显示和提前分页没有回归。
- 检查默认字号、深色、减少动态效果与至少 44pt 点击区域；优先实际手机体验。按用户 2026-10-19 要求，超大／最大辅助字号不再作为常规验收项目，仅在用户另行要求时专项验证；保留已有自适应和可访问性支持。
- 用实际截图和录屏审查动效；证据存仓库外，产品设计决策写入本文件与 `docs/decisions/`。
- 不把主观审美、自动化通过或模拟器运行说成获得苹果编辑推荐的保证。

## 兴趣与推荐控制

首次引导第四页和设置共用兴趣选择组件。标准字号两列，辅助字号一列；标签自然换行，不截断。0.14.0 起按用户要求，首次引导必须恰好选择三项后才能完成，没有跳过按钮；设置中的兴趣数量不受此限制，不替用户勾选。选中态使用 accent 的低透明底色、边框和勾选图标，并提供原生辅助功能选中状态。暗示性内容默认不出现，只在设置的「显示成人内容」开关打开后出现；选择人像不等于接受暴露画面，引导里也不放这个开关。页面只说明用户可控行为与本机隐私，不展示评分公式。

## 2.0：两步引导

引导只有两步：第一步是黑白卡片扇面和一句「好作品，是下一次创作的开始」；第二步选三个兴趣，必须恰好三项才能完成，没有跳过按钮（沿用 0.14.0 的规则）。0.14.0 的原创图片拼贴页和「复制到 ChatGPT」演示页已删除：一步使用在详情页里直接体验。设计稿的第三步（通知或小组件）等这两项功能存在后再加。兴趣格子仍是图标加文字，App 自带的原创图片不足以覆盖十二个兴趣。装饰只在当前页、前台、非低电量且未开启减少动态效果时运行；损坏的偏好文件保留错误并提供明确确认后的重置入口。

## 图标

界面上的图标是 Prompix 自己的一套描边图标（`PrompixIcon`，定义在 `TabSymbol.swift`），按设计稿的 SVG 在 24pt 网格上绘制：线宽 1.8、圆头圆角，渲染成模板图，在 Tab 栏、工具栏、菜单和按钮里和 SF Symbols 一样随色调变化。目前包括发现（指南针）、收藏（书签，实心表示已收藏）、搜索、返回、分享、铅笔、复制、对勾、加、关闭、筛选、展开、前往、外链、人像、更多、少推荐、播放、删除。系统菜单里的选中勾和空状态插图仍用系统样式。

## 搜索、专题与文本卡

搜索首页只有最近搜索和按用途；输入后才出现分类 Tab，并作为置顶的分组头固定在搜索框下方。不论在哪个分类下，结果网格都从同一高度开始（没有匹配的创作者时不留空位）。结果标题为 15pt。最近搜索里，一个词是另一个词的前缀时只保留最新的那个。专题页使用系统大标题，下面是一句说明，网格与信息流一样左右各 16pt；专题卡片的数量写成「27 条」。

文本卡片按引文排：底色是五种低饱和色之一（按作品编号固定，深色模式有对应的深色），没有描边；左上角一个浅色大引号，下面是 18pt 标题最多三行，西文用 New York，中文用宋体（Songti SC，系统可下载字体，到位前先用系统字体），日文用冬青明朝；再下面是 12.5pt 的一句简介最多三行（与标题相同时不重复），最后一行 9.5pt 等宽模型名（模型不明确就不写）。卡片高度按这几部分估算，所以信息流里文本卡高低错落。feed 卡片不带 Prompt 原文，简介用的是作品的 summary。中文、日文、韩文的 Prompt 整段用系统字体，只有西文 Prompt 用 New York 衬线体，避免中文里夹着的英文单词跳成衬线体。整段是 JSON 的 Prompt（约 2%）改用等宽字体，并按原文保留缩进，中文值仍显示为系统字体。筛选里不再有「参考图」。

## 区块标题与空状态

所有区块标题统一用 `SectionHeader`：15pt semibold ink，右侧可选一个 13pt muted 的「查看全部」。空状态统一用 `QuietEmpty`：左对齐，一句 20pt semibold，至多再加一句 15pt muted，不放插图。网页作品的截图从左上角开始显示，不从中间裁切。Skill 的 front matter 不在详情里单独显示，复制时仍然带上。收藏页右上角的设置按钮固定在最右，新建卡组按钮只在卡组分段出现在它左边，切换分段时设置按钮不动。

## 设置与看图

设置页只有可以点的行：你感兴趣的内容、重新查看引导、App 语言与系统设置；检查内容更新（右侧是最近更新日期）、清理图片缓存；帮助与反馈、隐私说明、内容来源与说明、开源项目。版本号以等宽小字放在最底部。说明性文字都在链接的网页里，不在 App 里堆叠；兴趣页也只留选项和开关。看图器只有右上角的关闭按钮和底部的系统页码点，左右滑动换图、下拉关闭，不再有上一张／下一张按钮。中文不使用等宽字体，数量用系统字体加等宽数字。Skill 没有个人版本，详情底栏只有复制；它的参数行写 SKILL。占位的模型名（通用对话模型、Agent Skills 等）不出现在参数行里。卡组封面是最近几件作品拼成的宫格，从不留空格：一件铺满，两件左右并排，三件左边一张、右边上下两张，四件及以上是 2×2。首页的创作者横条只放至少有三件作品的创作者。

## 内容范围

2026-11-07 起 Prompix 只收 X 和 prompts.chat 的图片、视频和文字提示词。分类是「全部 / 图片 / 视频 / 文本」，创作者页的筛选、搜索的分类和兴趣选项里都不再有网页和 Skill；用途分组里没有「网页与小工具」。底栏的复制按钮只写「复制 Prompt」，每条内容都可以写自己的版本。数据模型仍能读出旧的 skill 和 web 字段，避免已存的数据或缓存读坏，但界面不再展示它们。

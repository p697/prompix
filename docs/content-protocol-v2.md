# 按语言分发协议

状态（2026-10-12）：服务器双通道已部署，网络中断恢复与随后的普通每日重跑通过；当前v1和v2同为`edition-v2-d8f7fc6af6de6061`、346条九语，旧客户端继续使用 `/v1/latest.json`。原生0.3.2（9）已接入v2网络、缓存、个人数据事务和详情语言下载，148项模型测试干净通过，真实旧缓存升级、Release性能测量以及全部修复后的当前生产版语言UI复验均通过。最新签名候选同为0.3.2（9），本地归档与IPA审计见[交付记录](quality-release.md)；本轮没有安装用户手机。

## 要解决的问题

迁移前346条内容的紧凑九语目录为7,345,871字节，接近v1解码后的10 MB限制。每次内容更新都下载所有语言，既限制扩量，也增加首次更新等待。v2保留完整原文和所有来源、作者、Skill及媒体字段，把译文分为独立的不可变语言文件。用户需要哪一种语言，客户端下载哪一种；缺少对应译文时显示原文，不隐式下载或回退英语。

发布器内部仍使用完整多语言目录。拆分只发生在发布边界；继续审核、翻译、保留上次快照和回滚时，必须重新组装所有已发布语言，不能把某台设备只下载的一个语言当成完整发布状态。

## 数据约定

新清单使用 `schemaVersion: 2`、发布版本、时间、条目数，以及原文文件和各语言文件的描述符。描述符包含固定HTTPS地址、SHA-256、解码字节数及条目数。原文文件位于 `releases/<version>/v2/base.json`，语言文件位于 `releases/<version>/v2/locales/<locale>.json`。支持九种语言：`en`、`zh-Hans`、`zh-Hant`、`ja`、`ko`、`es`、`pt-BR`、`fr`、`de`。

原文文件保留原始字段与下架ID。已有本地化元数据保留来源语言和完整源文指纹，将译文字典替换为明确的可用语言列表；没有本地化元数据的原条目不补造来源语言。源文指纹覆盖标题、摘要、正文、示例、预览说明和封面文案，不能只比较Prompt正文。

每个语言文件绑定发布版本、时间、语言和原文文件哈希，包含条目ID、源文指纹及完整译文。该语言文件必须完整覆盖原文文件中宣告可用的条目；不接受重复、未知、已下架、未声明或指纹不一致的条目。语言缺项与“尚未下载”是不同状态，后者不能被当作撤回译文。

清单最多32,000字节；原文、每个语言文件，以及原文加任一所需语言文件的解码总量均不得超过10,000,000字节。此步保留1,000条上限，不靠提高单个路径的容量或静默截断来扩量。每个文件的哈希、实际字节、条目数和固定地址都要验证，HTTP压缩不能绕过上限。

## 发布与原生实现

纯拆分、验证、原文加单语言和全部语言重组均已实现，并使用仓库外真实目录验证无内容丢失。Worker只提供严格的只读路径。全部不可变文件上传并回读校验后才激活清单；重试复用原字节和发布时间。v1和v2的两个清单不是一个原子事务，分别验证并恢复中断。

当前完整v1仍在容量内，初始化没有冻结v1。以后若完整v1超过容量，保留最后一个可用快照，仅继续显式下架的兼容更新；缩量不自动解冻，不能把v2文件放到v1地址或隐瞒丢弃内容。完整v2已成为发布保留依据，后续目录不得从停留在旧版的v1重建。

服务器实现使用外部持久发布记录保存精确目标与观察到的指针身份，按v2、v1顺序激活。恢复先于每日准备工作，不重复模型调用；本地新增下架会重建原待发布目标。回滚和普通恢复共用相同的上传、回读与冲突检查，回滚另外在激活前验证媒体并保留暂停。Worker仅开放latest、原文与九种明确语言路径，支持条件GET／HEAD和流式读取；本机manifest/index不公开。初次开关、日常状态及手动恢复见[运行手册](content-operations.md#v2分语言通道)。

首次初始化可沿用旧版本及原字节；随后v2每日发布和新增下架后的普通待发布目标使用 `edition-v2-<hash>`。版本身份覆盖完整原文、全部译文、作者、媒体及去重排序后的下架ID，保留字符串空白和数组顺序，仅忽略对象键顺序，不包含目录发布时间。这样避免复用旧v1在修剪文本前计算的版本号；相同内容重跑仍复用不可变字节和时间戳，已发布旧版本不重写。

原生`Library`检查`/v2/latest.json`，默认只补下载App界面语言所需的文件，不隐式请求英语。`LanguagePackCache`按内容哈希保存经过校验的原文和语言文件；`language-packs.json`记录活动清单与已下载语言，`catalog.json`保留同一版本的可读投影。启动优先读取已缓存的App语言；已有v2文件损坏时可保留同版投影，不静默退回旧内置版。文件先暂存并回读，再把活动索引、目录、收藏、创作者及下架草稿清理放入现有回滚日志事务；任何阶段失败都恢复旧文件，重启先恢复日志再读取个人数据。

详情菜单列出经过源文指纹匹配的可用语言，区分可下载和已下载。显式切换只请求所选语言，自动刷新仍请求App偏好语言；缺少偏好语言包不阻止另一种已缓存语言离线使用。切换按当前文件哈希检查缓存，同版本缺少语言仍会下载。等待或失败时保留当前显示、复制和编辑内容，失败可重试，选择原文取消本次请求。每次请求都有任务身份，已取消的旧调用也不能取消较新的请求；下载、校验与提交之间再次检查身份、源文和下架状态。成功的显式安装同样取代旧下载，失败的显式安装保留原任务。健康且未变化的目录检查不重写活动索引或个人文件；损坏的普通缓存文件仍先重新验证和修复，再判断是否需要事务提交。

目录入口的详情跟随当前条目，收藏入口保留快照来源。只有完整源文指纹一致时才合并已下载译文；未下载但仍被声明可用的旧译文继续保留，明确撤回的语言才移除。标题、摘要或封面文案变化同样阻止把新译文混入旧快照。已打开收藏详情取消收藏后仍应用同源新版本的可用性，不能从导航快照复活撤回语言。编辑器在打开时固定Prompt及实际显示语言；后台更新不改变其恢复基线。草稿继续使用`id`和`id::locale`，下载和语言切换不改写草稿，明确下架才在事务内移除该条目的全部草稿变体。

非活动语言文件清理已实现。暂存前登记的租约保护仍在运行的写入及待接收结果，取消任务不会提前解除保护；指向同一目录的祖先路径别名共享租约。暂存完成、提交或拒绝后，在MainActor释放本次租约并清理，始终读取当前磁盘索引，保留原文、所有已下载语言和其他仍存活租约的文件。无效或缺失索引、任意回滚日志都会阻止清理。只删除规范SHA文件名的普通JSON文件，不跟随符号链接或递归删除目录；清理失败由后续重试，不撤销已成功的内容事务。

没有进行中的暂存、回滚或文件系统错误且清理成功时，受管理的活动文件最多10个（原文加九语），按协议上限总计不超过约90 MB。五个连续合成九语版本的清理回归确认每次均保留10个文件；这验证保留规则，不是数月使用实测。这也不是设备总存储的硬配额：活动索引、目录投影和个人文件另计，租约、待恢复日志或删除失败可能暂时保留旧文件。图片缓存清理与语言文件清理独立。

# 原文＋中文与独立处理队列

2026-10-18。本轮仅测试已有候选，不恢复历史搜索、不发布测试内容。批量扩库待本轮实测后决定。原始500条任务、失败账本和日常发布上限保持独立。

## 实现

- 私有 Postgres `queue_jobs` 保存采集、审核、翻译、语义复核和按需语言任务；`queue_attempts` 保存每次领取与结果。普通 Feed 读角色无权访问。
- 每一步单独领取，前置任务成功才可继续。事务内 `FOR UPDATE SKIP LOCKED` 领取后立即提交，调用外部服务时不持有数据库事务。
- 全局控制行限制同时执行的队列任务（默认3）；翻译任务内部并发1，不将不同 worker 的并发乘在一起。
- 任务身份绑定原始版本、批次、语言策略和依赖。重复入队不重复处理，改变内容须新身份。
- 租约续期与 fencing token 防止旧 worker 提交；超时/未知外部结果转 `reconcile`，保留尝试，不自动重复付费。已确认没有外部副作用的重试有指数退避和次数上限。
- 原文始终逐字保留。新队列只要求 `zh-Hans`；已有简中编辑元数据复用，正文真实翻译。旧九语任务配置不被重写，其他语言历史错误不因策略变更被清除。
- 复用审核缓存时仍检查精确原文、编辑元数据、媒体覆盖和尺度分类。进入翻译时核对审核产物摘要，接受输出时再次检查来源时效、撤回和质量暂缓。
- 中文继续通过原有变量、数值、JSON、字面文本、格式及拒绝记录检查，翻译使用 `gpt-6-luna`，并由 `gpt-6.1-sol` 独立逐条做语义复核。被标记内容不进入 ready，审核模型误报也须保留证据再处理。
- `ready` 是待验收产物，非公开发布；原来的发布、去重、撤回和日预算门槛仍有效。审核与语义检查属于内容数据，不能因为队列任务结束就等同于内容合格。

## 命令与运行边界

迁移：`supabase/migrations/20261018144941_independent_ingest_queues.sql`。

`tsx scripts/run-ingest-queue.ts enqueue ROOT SHARED RUN MANIFEST BASELINE` 将显式批次排入队列；不自动搜索。`drain ... [MAX_JOBS]` 有界消费；`status ...` 查看状态；`export ...` 重新验证后导出待验收记录。数据库凭据继续只来自仓库外环境；使用现有 TLS 校验的发布连接。每个进程串行执行短数据库操作，模型调用仍可并发；跨进程遇到发布角色连接上限时仅对尚未执行 SQL 的建连做有限退避，绝不重放未知事务。生产角色保持3连接上限。

多个独立 worker 可消费不同阶段；数据库持久化并不等于模型服务24小时运行。现阶段模型执行依赖这台 Mac 和 Codex 订阅，可恢复队列保存积压。`reconcile` 任务必须检查留存响应再恢复，不能删除尝试重新入队。源记录过期必须通过已有预算保护的来源复查，不改采集时间。

按需语言的内部入口 `requestLocaleTranslation` 以原文指纹＋locale＋模型/版本生成共享任务，语义通过前无可用译文；源记录删除或修改会阻止旧结果生效。它不接受用户自由文本，也不包含用户偏好。**移动端自动请求入口与公共接口限流尚未接入，本轮不会声称已上线按需翻译体验。** 现有缺失语言继续使用真实的原文回退。

## 验证与测量

`tsx scripts/benchmark-ingest-queues.ts INPUT_COHORT OUTPUT SHARED CODEX [LIMIT]`：测试最多500份已有内容。只读原批次，在独立外部目录建立持久化 PGlite/Postgres 队列，重验来源/完整媒体批准，清空中文正文缓存，真实翻译和语义复核，记录模型调用、token、耗时、合格和暂缓数量。最多200次模型请求；每个未知请求保留状态。

该测试的来源与图片审核为缓存重验，不能将其速度宣传为全冷采集链路速度。完整冷链估算需结合实测编辑/视觉耗时、获取合格率、审核返工和订阅可用额度。账号周用量为全账号读数，无法把期间所有变化归因到翻译任务。

首轮自动化覆盖依赖、幂等、跨任务全局并发、过期租约、旧 worker 提交、重试退避与上限、失败保留、读角色权限、原文不变、必需语言、精确语义证据及按需版本变更。首轮323条中文冷生成＋轻量语义复核用时17.97分钟，321条通过结构校验、2条暂缓。24条重新文字/完整媒体审核用时166.896秒，22条通过。小模型语义复核存在误报和漏检，改用更强审核模型；这部分全量对照与返修结果保存在仓库外验收报告中，不能把结构通过数当作最终合格数。

最终实测：321条全量强语义复核耗时495.103秒，257条通过、64条暂缓；连同2条结构失败，对66条定向返修耗时338.85秒，54条修复后通过。扣除2条新增画面不符记录，最终309条待验收、14条暂缓（239图片、69视频、1文本）。测试全程2420.105秒，包含反复校准。原文均逐字保留，0条公开发布。

本轮新增X请求与付费模型API支出均为0，使用现有Codex订阅；384次模型请求中162次为额外轻量审核对照。账号周用量读数45%→48%，包含开发和其他会话，不能精确归因或保证余量足够。24条完整冷审核为小样本，不能保证新来源保持同样通过率。按各阶段实际worker秒数、3并发及本轮合格率推算，一万条约31.7小时纯处理，加25–50%余量约40–48小时；新发现吞吐和订阅额度尚未证明能持续支撑，不能承诺两天完成。

生产私有迁移已应用；5个并发领取调用只领取3条、无重复，依赖顺序与公开版本不变已实测。发布角色保留3连接上限。安全检查无告警，Feed/anon/authenticated无法读取队列表。批量采集与公开发布保持暂停，验收产物在仓库外保存。

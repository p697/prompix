# 0.8.3（37）：恢复首页滚动顶栏

0.8.1（PR108）为下拉刷新改动首页布局时，一并移除了 `readingChrome`、收起状态与渐变叠层。0.8.2 未发现这一回归，实际向下浏览仍显示固定顶栏。

本轮恢复原有滚动方向检测：向下阅读收起，反向滚动展开，切换分类与回到顶部恢复。使用现有 `ReadingScrollState` 阈值和回弹处理；VoiceOver 保持入口可见，减少动态效果设置关闭位移动画。

刷新控件仍位于稳定高度的安全区下方，Header 独立叠放并恢复渐变，收起不改变内容偏移或留下占位白块。没有改动最新排序、分页、创作者加载或详情布局。

## 验证

证据在外置开发盘 `Prompix-Codex/Evidence/header-collapse-20261015/`。修复前录像和截图显示滚动后顶栏仍固定。首轮视觉恢复后，XCTest 的 `isHittable` 对重新出现的 SwiftUI 顶栏返回 false；实际截图和坐标点击证实按钮可操作，因此最终测试使用位置断言并真实打开设置页验证，不将该自动化属性误判当作新的产品故障。

最终验收 `acceptance.xcresult`：2 个滚动状态单元测试与 2 个 UI 测试全部通过。覆盖下滑收起、反向展开后打开设置、分类切换复位、再次收起/展开，以及下拉刷新和离线缓存。已检查 `acceptance-shots/` 的收起、展开、分类复位截图。测试设备为独立 iPhone Air 模拟器；测试使用隔离数据，不修改验收手机的收藏。

交付版本为 0.8.3（37）；签名包与安装结果保存在开发盘 `Prompix-Codex/Releases/0.8.3-37/`。VoiceOver 和减少动态效果沿用现有支持，本轮未声称完成辅助功能手动验收。

## 已验证行为

内容与协议检查：96 项通过（后续翻译回归需最终重跑）。定时器 12 项通过。界面字符串检查覆盖翻译状态、占位符、复数与回退脚本。`Quality-Global-Identity-Recovery-Motion-7.xcresult` 中 62 项原生模型检查全部通过，包含作者身份迁移、四个写入阶段失败、回滚失败后重启恢复、损坏日志保留、下架内容的旧页面保存防护，以及旧用户名／已验证数字账号的目录合并和冲突身份隔离。

iPhone 18 Pro / iOS 27、Release 构建的 `Quality-Global-Core-7.xcresult` 验证了：

- 首页作者 → 作者主页 → 作品详情 → 作者主页的实际点击链路。
- 收藏创作者后结束进程，再启动，在收藏页找到该作者。
- Skills 频道 → 真实 Skill 详情 → 原始文件与安装说明入口 → 复制和收藏。
- 选择英文内容，在英文草稿中写入测试标记并保存；原文草稿不含该标记；再次打开英文草稿标记仍在；恢复译文只还原该语言。

`Quality-Global-Core-7.xcresult` 另外完成 20 次作者主页／内容类型来回切换。iPhone 17e 的深色、最大辅助字级下，`Quality-Global-Small-AX-7c.xcresult` 完成作者／Skill 阅读收藏、文本阅读编辑、专题与旋转检查；简化后的大字号文本卡片已查看截图。

测试发现并修复了混用值导航和直接导航导致作者作品无法打开的问题。首页/作者页面的容器标识曾覆盖子控件的可访问性标识，已去除。后续视觉检查还修正了 Skill 分类的绑定状态和重复标题，并将文本与 Skill 详情改为直接阅读；这些改动已纳入 iPad 的 `Quality-Global-iPad-7b.xcresult` 两条完整流程，包括横竖屏专题、复制、编辑、作者、Skill 与收藏。iPad 专题采用两列布局，详情最大阅读宽度为 700 点，已检查实际截图。

`Quality-Global-Identity-Recovery-Motion-7.xcresult` 还验证了真实模拟器写入冲突下保留编辑缓冲区、明确退出与恢复，以及开启“减弱动态效果”后的图片缩放返回；测试后已恢复设置。VoiceOver 首页实际语音遍历通过，详情编辑复制流程仍在复核合成事件与键盘切换。

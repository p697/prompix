# 设计方向与交互要求

更新：2026-10-15。0.9.0 在 Cosmos 式轻盈发现之上，采用用户确认的 FIELD / IBM Quantum 视觉参考，落实为原创展开卡片、冷白与深墨底色、蓝色操作与局部光谱。实现和验收范围见[本轮记录](design-spectral-0.9.0.md)；不把设计目标或主观评价作为苹果编辑推荐的证明。

## 1. 核心原则与参考

像逛手机淘宝和小红书一样发现有意思的 Prompt：用户即使没有任务，也愿意多看几屏。内容、真实创作者和具体用途构成浏览理由。页面不添加「灵感随手可得」「DAILY FINDS」等装饰口号，不伪造人气、粉丝数或收藏数。

[设计调研](design-research-2026-10.md) 记录 Apple 官方设计奖与 App Store 页面，以及 Cosmos、Are.na 等产品的实际截图观察。借鉴内容层次、清晰操作和组织方式；参考产品是否获奖与 Prompix 的质量评价分别记录，静态截图研究不能代替完整交互验收。

采用冷白／深墨背景与清楚的文字层级，由真实作品承担大部分颜色。系统字体用于正文、标题和字标；媒体卡采用小圆角与紧凑标题，避免额外边框和阴影。局部蓝紫光谱用于引导与品牌标记，不覆盖照片或 Prompt 正文。发现／收藏与右侧独立搜索使用原生 TabView、SF Symbols 与系统玻璃效果；优先原生导航、菜单、分享、编辑和播放器。支持暗色模式、动态字体与减少动态效果。

## 2. 页面与信息层次

| 页面 | 当前内容与行为 |
|---|---|
| 发现 | 全部／文本／图片／视频／网页／Skill；无筛选时显示创作者横栏、用途专题和全部内容流；用途与模型置于原生筛选菜单 |
| 筛选结果 | 隐藏创作者和专题模块，显示实际结果数量、清除入口与有操作指引的空态；选中类别与内容同步 |
| 搜索 | 原生搜索、内容结果和作者结果、本机最近搜索；输入为空时显示具体用途建议 |
| 创作者 | 首页横栏、可搜索目录、真实身份与头像、简介、收录数量、内容分类、原平台入口、本地收藏 |
| 详情 | 有实际媒体时展示预览；文本和 Skill 直接进入标题、说明与正文；作者署名可进入主页，原文／译文可切换 |
| 使用 | 当前语言的完整正文可编辑、复制与系统分享；按语言保存独立草稿，失败保留文本；打开工具不声称已经预填或执行 |
| 专题 | 按实际用途组织内容；封面来自实际条目，数量与内容使用同一筛选结果 |
| 收藏 | 内容／创作者原生切换；内容可搜索并按类型筛选；保存本地快照、正文草稿、缩略图与头像 |
| 设置与支持 | 内容更新、缓存管理、App 语言入口、隐私、来源说明、联系与内容反馈 |

主导航为发现、收藏和右侧独立搜索。专题从发现页进入，不占用独立 Tab。详情覆盖底层 Tab，返回过程中即可看到原 Tab；滚动时顶部控件按方向收起和展开。设置使用原生 sheet，保留浏览位置。

## 3. 卡片与详情

- **文本**：短标题、具体用途和示例。封面帮助识别内容；无实际媒体的详情不再重复大幅装饰封面，优先阅读。
- **图片**：实际效果图优先，区分参考图和输出；详情支持缩放与 1–8 张图集，只展示与正文核对对应的媒体。
- **视频**：封面与播放入口清楚；列表不自动播放，详情明确点击后播放，关闭或进入后台暂停。
- **网页**：作品截图与具体用途；允许的原创示例可在隔离的 WebKit 中打开，外部示例标明入口，不把网页录屏误归为视频 Prompt。
- **Skill**：具体能力与真实来源，避免伪造效果图；卡片标题不在封面下重复堆叠。详情展示完整 SKILL.md、适用工具、已核验文件和固定版本源目录，说明应取得完整目录，不把复制说明当作安装。

卡片主区域打开内容，作者行独立打开主页，收藏按钮独立操作。媒体加载失败提供真实状态和重试；作者缺少头像时用姓名首字占位，不生成假人像。正文长于预览范围时可展开；收起状态的复制和分享仍使用完整正文。

## 4. 创作者与浏览节奏

作者按稳定平台身份聚合，同名作者不合并。横栏名称允许两行，不能只剩截断账号；大字号使用可完整阅读的行布局。目录与主页的数量只表示实际收录内容，本地收藏作者不等于在 X 或 GitHub 关注。

默认混合发现，不要求先懂模型名。创作者、用途专题和完整内容流各承担一个任务，筛选之后直接进入结果。控制同作者相邻重复和单一类型扎堆；相关内容按具体标签、类型和模型选择，不用通用标签反复推荐相同内容。Prompt 保持主角，Skill 作为明确可选的内容类型。

## 5. 国际化、原生与可访问性

界面资源覆盖英文、简体中文、繁体中文、日文、韩文、西班牙文、巴西葡萄牙文、法文和德文。内容按当前语言选择已存在的完整译文，显示 AI 译文标识；缺失时明确回到原文，原文始终可以选择。当前345条内容已覆盖九语言完整记录；代理校验与语义审核不等于专业母语审校。

- 窄屏双列、常规宽度三列；辅助字号或 VoiceOver 开启时采用按编辑顺序排列的单列，避免瀑布流按整列朗读。
- 实际触控区域至少 44pt，系统字号可增长，标题与模型信息可换行或改为纵向布局。语言名称、德语等长标签和中日韩文字分别检查。
- 原生返回手势、搜索、菜单、键盘、图片缩放、系统分享和媒体播放保持一致行为；Tab 图标与文字都可识别当前选择。
- 编辑页键盘、大字号和保存失败时，正文、复制及恢复操作均可到达。恢复当前语言只影响该语言草稿。
- 收藏的离线能力包括本地正文、已保存缩略图和头像；在线网页与未缓存视频显示实际不可用状态。清理浏览缓存保留已收藏媒体。

## 6. 本轮模拟器验收

以下是完成关口，不是已通过记录。检查证据与待办统一维护在 [next-release.md](next-release.md) 和本地化、质量记录中。本阶段不向用户手机安装。

1. 从首页作者进入主页，过滤到某类作品，再进入详情；返回两次恢复作者筛选和首页位置。卡片内容、署名、收藏三个区域分别触发正确操作。
2. 在同一详情切换原文与可用译文，分别编辑、保存并重启；两份草稿独立，完整复制结果与当前语言一致。缺失译文、长正文和失败恢复分别演示。
3. 进入 Skill，查看正文、文件和固定版本源目录，收藏后从收藏页重新打开。界面不声称已经安装或运行。
4. 按类别、用途、模型筛选，检查选中态、实际数量、空态和清除；搜索作者、内容并清除最近搜索，验证导航可继续使用。
5. 检查小屏、常规屏、宽屏、深色、辅助字号与 VoiceOver 顺序；至少实际查看中英日与较长翻译的布局，九语资源检查另行记录。
6. 保存真实截图与演示录像，覆盖发现、作者、内容使用、Skill 和收藏；区分已演示、自动化验证和仍需后续验证的部分。

## 7. 历史稿边界

[`design/v2/`](../design/v2/index.html) 保留历史 HTML 静态稿，仅供布局思路参考，颜色、虚构数值、以图搜、同步、个性化频道均不代表当前范围。Skill 已通过本轮原生实现进入 0.3.0，不能继续因为旧稿曾提及它而将其写为后置。完整范围以 [产品定义](product.md) 为准；不按旧稿十屏逐屏验收。


## 2026-10-12 视觉方向更新：Granola

用户最新指定Granola为整体设计参考，替代本文件早期尚未收敛的视觉描述。实现规范与原始视觉来源见[Granola研究](design-granola-2026-10.md)。保留图片内容的发现式瀑布流，文本和Skill采用可读内容样本；原生页头缩小并左对齐，纸张底色覆盖首页、创作者、专题、详情、编辑、收藏和设置。系统导航与无障碍行为优先。

创作者入口不再因旧缓存无作者字段而消失。首页更新状态明确说明当前仍可浏览已下载内容；成功时自动展示新作者，失败时能重试。内容数量不能被包装成与当前设备状态无关的宣传数字。

# 0.7.1（32）：详情渐进呈现

分页详情不再先展示居中的 Loading 页面。列表卡片已经持有的封面、标题、简介和作者立即参与原生放大转场；只有尚未取得的正文显示静态骨架。完整内容通过原有版本校验后替换占位，复制、编辑、使用与收藏操作才出现。

## 实现边界

- 复用现有 `ContentPreview`，不把列表摘要伪装为完整 `Prompt`。没有新增全库预取或更改 API。
- 待加载和完整详情共用封面尺寸、标题排版；iOS 18+ 通过系统 `ScrollPosition` 保留等待中滚动的位置。iOS 17 保留渐进展示，但没有跨阶段的精确像素位置恢复；未在本轮实际运行 iOS 17。
- `RemoteImage` 首帧直接读取现有内存图片，保留磁盘/离线图片原有下载策略；离线缩略图读取后同样进入内存。未知图片只保留底色，不再显示图片中央转圈。
- 已完整下载且版本、语言相符的内存详情可同步展示。版本变化、尚未下载的语言和已下架记录不使用这一快速路径。
- 失败时保留封面和标题，在正文位置显示重试，沿用限流冷却时间；下架则使用原有下架提示。关闭页面取消该次请求，迟到结果不能补入下一条内容。
- 已有详情覆盖层和底层 Tab 的关系不变；视频仍需主动点播放，详情打开不创建播放器。
- 静态骨架不引入闪烁或循环动画，支持 Dynamic Type，并向 VoiceOver 提供一个加载状态而非逐条朗读装饰线条。

## 验证

工具链 Xcode 27.1 RC；普通 iPhone 18 Pro 模拟器（iOS 27.0，`C0DB1FE2-71F3-4EF6-AEFF-8FECEA472A92`）。证据位于开发 SSD `Prompix-Codex/Evidence/progressive-detail-20261015/`。

`progressive-final.xcresult`：12 项通过、0 失败。9 项模型/缓存测试覆盖版本与语言隔离、下架、个人存储回滚、图片同步缓存和离线缩略图；3 条 UI 流程覆盖文本/图片/视频/网页的渐进展示、正文到达前关闭、错误恢复、二次打开缓存，以及响应前后标题纵向坐标保持在 5 pt 容差内。接口通过仅 Debug 模拟器编译的受控服务暂停，检查首帧后由测试释放响应；不是依靠短暂网速波动碰巧截到骨架。

`verified-captures/` 保存实际截图。初次测试曾因父级无障碍 identifier 覆盖重试按钮而失败，补充包含语义后重新运行通过；初次结果单独保存在 `progressive-ui.xcresult`，不计为通过证据。

九语言资源检查通过。本轮没有新增界面文案键，没有把测试内容发布到线上，也不修改用户收藏和草稿。

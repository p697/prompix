# 0.3.3：从内容浏览重新整理视觉层级

2026-10-13：用户再次指出0.3.2没有达到期待的设计质量，要求多看App Store榜单和编辑推荐的产品图，反思后直接实现下一版。测试通过不能作为设计认可；这一轮以实际页面与浏览行为为判断依据。

## 对上一版的具体批评

1. 分类、创作者、用途专题、全部内容计数形成四层页头，作品出现得太晚。第一屏更像功能入口集合，不像正在逛内容。
2. 中文标题和文字卡同时偏大，颜色块、圆角与文字都有较强存在感，缺少安静的辅助层级。
3. 滚动后切换类型必须回到顶部；复制需要每次打开详情。原有操作虽可用，却增加了反复浏览的步骤。
4. Tab图标的尺寸和线条没有与内容整体比例一起复查。第一轮改回SwiftUI系统符号后，iOS27又强制将三枚图标渲染为偏重的实心形态，因此也没有直接接受。

## 本轮实现

- 原生发现页保留分类并随滚动固定，切换类型或筛选后回到首个结果。
- 正常字号下创作者收为一行，保留头像、姓名、条目数和目录入口；大字号、VoiceOver和缺作者资料仍使用完整说明布局。
- 首页先呈现六条真实内容，再穿插用途专题，后续继续完整目录；不增加虚构的热门度或个性化推荐标签。
- 文字卡缩短并减少色彩重量，深色采用单独适配色；图片标题最多两行，作者与收藏仍独立可操作。
- Tab继续使用原生TabView的选中、着色和触控行为，SF Symbols按统一25pt画布、21pt光学边界渲染为模板图像，避免iOS27强制替换为实心变体。发现使用双列内容符号；卡片长按提供原生复制与收藏菜单。
- iOS18及以上使用系统卡片放大转场；Reduce Motion及旧系统保持标准导航。详情标题从largeTitle调整为title。

## 验证

在专用iPhone18Pro / iOS27模拟器，使用Release构建验证，未操作用户手机：

- 最终352条生产目录：创作者主页、滚动后固定分类、切换分类回首条、原生长按复制、详情、编辑、返回保持分类、专题和收藏的完整UI用例通过（39.776秒）。截图逐屏查看，最终Tab线条与尺寸已复核。
- 中文、英文、德文界面的首页、详情、复制、编辑UI用例通过。此处测试界面本地化与原文回退，不冒充已下载全部目标语言内容的测试。
- 深色 + 最大辅助字号：点击区域/元素描述无障碍审计、浏览、复制、编辑后复制、专题与横屏流程通过；这条使用离线30条目录，不冒充352条全量无障碍审查。另查看常规字号的真实352条深色首页。
- 九种语言213项界面文案覆盖、占位符、复数和回退检查通过。
- 首次build-for-testing因未开启测试可见性而失败，补充ENABLE_TESTABILITY后构建成功。第二轮UI运行时本机磁盘耗尽、测试进程意外退出；清理可重建编译缓存后，第三轮最终用例成功。失败运行未计入通过结果。
- 验收后恢复自用模拟器原有收藏、草稿、缓存与偏好，9个文件哈希全部与开始前一致；恢复浅色、常规字号和竖屏。
- 原始xcresult、截图和30秒模拟器操作录像位于开发机`~/.local/share/prompix/design-polish-10/`，仅实际素材构成演示，不把静态网页称作原生App。

通过以上检查只说明这一轮限定场景可用。尚未获得用户对新设计的认可，也不代表Apple编辑推荐、真机性能复验或所有系统版本的视觉验收。

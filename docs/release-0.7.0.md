1. 打开发现页，首屏即可浏览；向下滚动才加载更多。进入不同内容类型、专题或创作者，确认筛选与返回位置连续。
2. 在搜索页搜索“塔罗”或一个作者名称；打开详情检查完整正文、来源和复制。搜索覆盖数据库全库，不限于已滚动的页面。
3. 收藏一条内容并编辑个人草稿；切换阅读版本/我的修改，确认不会互相覆盖。
4. 在详情选择可用语言，确认只加载当前条目的语言；未完成或失败时仍保留当前正文。
5. 断网重启后打开已有收藏和草稿；联网后重试更新。尚未下载的详情会明确提示重试。
6. 从设置重放引导，试用内置 Prompt 后返回，确认引导与正式浏览互不干扰。

完整技术证据、首个自然输入运行及合入状态见[数据库 Feed 记录](database-feed-v3.md)，维护流程见[数据库运维](database-operations.md)。用户体验是否达到预期仍由本次验收决定。

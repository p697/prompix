# Granola 设计研究与 Prompix 原生适配

研究日期：2026-10-12。用户指定 Granola 为新的视觉参照；Prompix 继续提供多模态内容发现、创作者、专题和收藏。本文区分实际观察与我们的设计决定，不能以视觉参照代替真实设备上的功能验证。

## 已核查的视觉依据

通过浏览器查看了用户提供的 [App Store 页面](https://apps.apple.com/us/app/granola-ai-meeting-notes/id6739429409?l=zh-Hans-CN) 的 10 张预览图、[官网首页](https://www.granola.ai/) 和 [官方改版说明](https://www.granola.ai/blog/a-new-look-for-granola)。没有登录 Granola，也没有实际操作其 iOS App；手势、性能、动效时长和完整导航不能仅凭截图推断。

| 实际观察 | 对 Prompix 的启发 |
|---|---|
| 产品内是浅暖灰、略带绿色的纸张底色，深灰文字；彩色宣传背景在产品窗口之外 | 用统一的纸张画布承托内容，强调色只承担选中和主操作 |
| 笔记标题为普通字重衬线字体，正文和控件为无衬线字体 | 建立标题与操作文字的层级，减少多个粗体标题互相争夺注意力 |
| 日期、参与者、附件等元数据使用细边框胶囊和小型线性图标 | 作者、来源、语言和类型信息应轻巧、易扫读 |
| 正文直接排在页面上，以留白、字号和段落分层 | 详情与编辑以阅读和使用为中心，避免层层卡片包裹 |
| 返回、搜索、分享等操作采用小型圆形或胶囊控件 | 保留足够点击面积，同时降低控件的视觉重量 |
| 酸橙绿、粉紫、手绘线条和照片拼贴主要用于品牌宣传 | 不将宣传海报照搬为每一张内容卡或整屏背景 |

官方改版文章明确介绍了 Quadrant 展示字体与 Melange 界面字体，以及手绘标志。Prompix 使用系统字体适配这种层级关系，**没有使用或声称复刻这两款字体**。截图中也没有与 Prompix 对应的三 Tab 浏览结构；我们的信息架构由内容发现任务决定。

## Prompix 的原生设计语言

以下数值是 Prompix 自己的适配，**不是测量得到的 Granola token**。实现以 [Theme.swift](../ios/Prompix/Views/Theme.swift) 为准。

| Token | 浅色 | 深色 | 作用 |
|---|---|---|---|
| `paper` | `#F5F4EE` | `#1E221C` | 页面画布 |
| `surface` | `#FFFFFF` | `#292E25` | 需要区分层级的内容和控件 |
| `soft` | `#ECEEE4` | `#30362B` | 辅助分组与轻背景 |
| `ink` | `#252A22` | `#F1F2E9` | 主文字 |
| `muted` | `#62685B` | `#B8BFAC` | 次级信息 |
| `accent` | `#435332` | `#D1E190` | 强调文字和图标 |
| `highlight` | `#D6E579` | `#C8D974` | 选中与主操作背景 |
| `line` | `#DCE0D2` | `#434A3B` | 轻分隔与描边 |

深色模式由 Prompix 自行设计，不声称来自 Granola 夜间截图。强调背景搭配专用深色文字，避免用浅色强调字叠在浅色高亮上。

`Typography.editorial` 使用系统 serif、regular 字重及语义字号；正文、按钮和元数据使用系统 sans。保留 Dynamic Type 与各语言的系统字形回退，中文和日文无需强行模拟英文衬线的形状。颜色不作为选中状态的唯一标识。

页面边距以 20pt 为基准，控件点击区域至少 44pt；留白服务于分组与阅读，不通过巨大页头挤压内容。采用 SF Symbols、原生 TabView、NavigationStack、Sheet、菜单和文本编辑能力，交互遵循系统习惯。

## 按页面落实

| 页面 | 设计决定 |
|---|---|
| 发现 | 采用小而左对齐的品牌标题、轻量筛选；图片保持瀑布流，文字卡展示真实内容样本；创作者入口在首页明确可见 |
| 创作者 | 头像、姓名、作品数量形成稳定层级；目录支持直接搜索，主页提供作品和来源跳转；身份信息比装饰更突出 |
| 内容卡 | 统一圆角与文字对齐；不叠加常驻重阴影；弱化占面积的装饰符号，避免重复显示同一标题 |
| 详情与编辑 | 标题、作者、语言、正文依次展开；复制作为主要动作，收藏和分享作为次要动作；保留原文、译文及草稿能力 |
| 专题与收藏 | 沿用同一套纸张、文字和元数据样式；用作品或真实预览区分专题，空状态文案直接说明下一步 |
| 设置与弹层 | 原生导航、表单、选择器和关闭行为；语言、内容更新和版本信息应易于找到 |

Prompix 保留自己的名称、图标与内容资产，不使用 Granola 的漩涡标志、品牌插画或字体文件。动效优先采用系统导航与状态反馈，并尊重 Reduce Motion；研究没有验证 Granola 的具体动画参数。

## 验证要求

- 对首页、创作者目录、创作者主页、详情、编辑、专题、收藏、设置进行实际截图审查；不能只验收首屏换色。
- 覆盖中英文、长标题、九种已支持语言、深色、大字号和窄屏；检查内容遮挡、文本截断、控件命中区域与对比度。
- 创作者入口在缓存旧内容、更新中和更新失败时仍可理解；内容数量和版本信息必须与实际安装包、实际数据一致。
- 视觉与功能验证结果写入本次验收记录；本研究不等于已通过质量验收，也不构成 App Store 编辑推荐保证。

## 当前研发主线

基础功能与自建管线已经可用，完整产品研发尚未收尾。下一阶段优先完成真实用户的连续使用：发现合适内容 → 理解用途与前提 → 修改自己的需求 → 交给目标工具 → 收藏后再次使用。以当前构建实际遇到的交互、状态反馈、加载、内容呈现和恢复问题驱动修改，不以继续增加条目代替客户端完成度。

本轮内容批次按已有预算完成审核、翻译与发布，收尾验证后常规增量交给定时管线，只有采集／发布故障、实质质量问题或明确供给缺口才中断客户端主线。最终外部工具、性能、弱网和跨设备证据仍须补齐，阶段真机安装不关闭这些关口。

更新：2026-10-12。负责人最新验收将 0.2.0 评为勉强及格，本阶段不以修复旧候选版或增加条目数量为完成。目标是交付有明显品质提升、可以完整演示的原生 iOS 产品。当前模拟器交付检查已完成；线上345条×9语言，交付证据见[0.3验收记录](acceptance-0.3.md)，用户产品验收仍待。

## 当前目标

- 完整创作者链路：首页发现、作者目录、真实平台身份和头像、个人页、收录内容、原平台跳转。公开资料通过项目 API 与公开来源获取，不把显示名当成唯一身份，不伪造粉丝数或关注关系。
- 内容与界面国际化：英语、简体中文、繁体中文、日语、韩语、西班牙语、巴西葡萄牙语、法语、德语。保留原文；按语言选择译文，编辑和复制使用当前选择，译文草稿与原文草稿独立。源文变化使旧译文失效。
- 增量翻译：已验证可用的 GPT-5.6 Luna、本机授权与持久缓存、受控批次、保留变量/代码/参数/链接，完整校验后发布。本机 CLI 不支持 GPT-6.1 Sol；早期通过的 Terra 译文保留并记录模型来源。翻译和原文数据留在仓库外；界面字符串进入版本控制。
- Skill 作为独立内容形式：真实 SKILL.md、用途、兼容环境、所需文件和源仓库，支持阅读、收藏、分享与前往安装说明；不声称 iOS 内能运行 Agent Skill。
- 多来源持续供给：现有 YouMind 三个公开库、prompts.chat 和 X 发现流继续运行，新增官方开放 Skill 来源，清楚呈现平台、作者与采集来源的区别。
- 发现体验：基于 Apple 官方推荐/设计奖和 Cosmos 实际页面研究，完善创作者、专题、完整内容流的层次、筛选后的结果反馈、详情复用、收藏管理与原生导航。保留轻盈克制，不重新添加空泛口号或虚构热度。

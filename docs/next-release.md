## 仍须完成的工作

1. **内容可用性和覆盖。** 继续获取独立的优质文本、图片、视频、网页 Prompt 与 Skill，尤其是非开发类用途；暂缓候选按真实缺口处理，不能为了数量批准空壳或错配预览。继续扩大可持续来源，观察自然调度和容量门槛。
2. **新增内容翻译。** 界面九语完整不等于内容九语完整。448 条版的语言覆盖分别为 en 387、zh-Hans 376、zh-Hant 377、ja 376、ko 375、es 375、pt-BR 376、fr 376、de 377；剩余进入预算内队列并抽检，保留原文回退。
3. **完整使用闭环。** Lovable 未登录浏览器已验证文本预填且未发送；Claude Code 仅验证官方链接、登录回跳和模拟器交接。最终仍须在适用账号和真实目标 App 检查原生唤起、完整预填、参考文件、取消及失败路径。不把进入浏览器等同于完成生成。
4. **当前构建的整体质量。** 448 条中文缓存目录的 Release 启动／滚动／内存已实测通过（启动均值 3.655 秒、滚动峰值均值 145.79 MB，见[质量记录](quality-release.md)）。新增使用面板已完成中／德／日三语最大字号、全文展开及 Skill 实际 VoiceOver 复验；iPad 完成真实 345→448 条升级、个人数据保留及四条中文竖屏功能流程。HTTP(S) URLSession 故障下的缓存编辑、重启保留、真实生产重试与编辑稿交接已通过；慢网、视频及完整离线、其他语言／屏幕、iPad 横屏／分屏和最终版本集中复查仍须继续。0.3.2 的 346 条性能证据不能标成 448 条或真机性能。
5. **产品与视觉验收。** 保留 Granola 的克制纸色、原生结构及丰富发现体验；用真实数据完整走发现→作者／专题→详情→编辑／使用→收藏→再次使用。局部绿色测试不能代表用户已经认可新版 UI，更不能保证 Apple 编辑推荐。
6. **最终分发与上架。** 从最终提交重新归档、导出、审计资源和隐私，准备匹配构建的商店素材；在用户认可最终演示后集中真机验收。发行账号资料和用户提交审核授权依照[商店准备](app-store.md)核对，旧 IPA 不冒充当前安装包。

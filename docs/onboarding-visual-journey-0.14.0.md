## 四屏

1. 七片独立色彩的玻璃从叠合展开，沿用 App Icon 的冰蓝、蓝紫与粉紫连续渐变及细白边，收拢展开角度与圆角比例。字标与标题分层入场，主按钮采用深墨胶囊及按压反馈。
2. 原创橘子摄影、湖泊和纸艺作品组成错层拼贴，轻微浮动；没有纯文字样例或装饰性的收藏按钮。这些随包作品由 Prompix Studio 制作，不需额外联网。
3. 图片 Prompt 与 ChatGPT 之间只有一个清楚的方向。点击“复制并打开 ChatGPT”复制随包橘子案例的完整 Prompt，复用正式 `PromptDestination` 打开官方入口；说明要求用户粘贴，未声称自动发送或生成。打开失败仍保留已复制内容，并提供说明；返回不完成引导。详情里的完整编辑／版本选择／其他工具仍然保留。
4. 十二个方向沿用同一兴趣分类和本地推荐存储，必须选三项，选满后可取消再换。画面克制程度仍是独立开关，选择人像不等于接受暴露画面。隐私和画面偏好的详细说明留在设置；设置仍允许自由选择任意数量。

## 状态与可访问性

- 首次引导直接作为根画面，不先显示发现页再弹全屏 cover，避免冷启动闪出首页与引导期间的提前曝光。设置重放仍保留原页面状态。
- 引导完成的按钮状态和实际执行都校验三项及持久化成功。下拉关闭、离开 ChatGPT、重新启动不会绕开未完成状态。
- 设置重放保持已有选择；如果之前在设置选了超过三项，需要主动减少到三项，代码不会默默丢弃兴趣。
- 偏好文件无法读取时不覆盖原文件；通过明确确认后的重置入口恢复，避免强制引导成为死路。
- 图形固定在测量区域，说明可自然换行；辅助字号下纵向滚动，兴趣改单列，主按钮保持在底部。
- 图形入场、标题淡入、页间过渡、选择反馈与按钮按压是各自独立的动效。装饰上限30fps，只在当前页、前台、非低电量且未开启减少动态效果时更新。减少动态效果直接展示静态完整构图，所有按钮不等待动画结束。
- 九语文案完整，保留 VoiceOver 标题、页数、按钮标签、兴趣选中状态。截图与自动化不等同于完整的 VoiceOver 人工遍历，也不作为苹果编辑推荐的保证。

## 调研结论

YouMind OpenLab 公开的 [README 同步工作流](https://github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts/blob/main/.github/workflows/update-readme.yml) 每四小时从 CMS 同步；[CMS 客户端](https://github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts/blob/main/scripts/utils/cms-client.ts) 说明公开仓库是发布侧，不能据此认定公开了完整 Twitter 爬虫。Prompix 自己持有查询策略、原始快照、作者身份、审核、翻译和发布记录。

产品参考各取其适用部分：[PromptHero](https://prompthero.com/) 的作品发现与模型筛选、[PromptBase](https://promptbase.com/) 的用途分类、[FlowGPT](https://flowgpt.com/) 的使用入口、[Skills](https://skills.sh/docs/cli) 的完整目录安装。研究这些产品不等于抓取它们的数据。最终体验应连通「发现内容 → 看作者与示例 → 修改或选语言 → 交给工具使用」。

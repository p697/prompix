# 自建采集与内容使用升级

2026-10-13。响应产品负责人明确要求：借鉴聚合产品的结构和技术，不把其他聚合站的内容库当作 Prompix 的长期供给。

## 调研结论

YouMind OpenLab 公开的 [README 同步工作流](https://github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts/blob/main/.github/workflows/update-readme.yml) 每四小时从 CMS 同步；[CMS 客户端](https://github.com/YouMind-OpenLab/awesome-nano-banana-pro-prompts/blob/main/scripts/utils/cms-client.ts) 说明公开仓库是发布侧，不能据此认定公开了完整 Twitter 爬虫。Prompix 自己持有查询策略、原始快照、作者身份、审核、翻译和发布记录。

产品参考各取其适用部分：[PromptHero](https://prompthero.com/) 的作品发现与模型筛选、[PromptBase](https://promptbase.com/) 的用途分类、[FlowGPT](https://flowgpt.com/) 的使用入口、[Skills](https://skills.sh/docs/cli) 的完整目录安装。研究这些产品不等于抓取它们的数据。最终体验应连通「发现内容 → 看作者与示例 → 修改或选语言 → 交给工具使用」。

## 已实现的第一轮

- 定时主链停止获取四个 OpenLab 仓库及视频归档。历史已发布内容保持署名与稳定 ID，保留用户收藏；新增供给不再依赖 OpenLab。
- X 官方 API 独立搜索图片、视频、文本、网页和 Skill 五个主题；按主题轮换，不绑定其他聚合站的作者名单。
- 每个查询保存独立分页游标，完整读完分页窗口才推进高水位；超过 48 小时的分页 token 从已提交高水位重新读，重叠记录按帖子 ID 去重。
- 默认每日最多 4 次搜索、200 个帖子额度，每次最多 50 个。迁移时保留旧采集器当天已消耗的额度，失败或中断不自动重试，也不通过提高配置绕过不确定的已付费请求。
- 保存完整长文、附件关联、原始链接、作者 ID/用户名/头像；同日快照按真实抓取时间排序，新的作者资料优先于旧缓存。
- 官方 Skill 目录从 10 个扩大到 35 个。直接获取 Anthropic/OpenAI 作者仓库，逐目录确认许可证、固定 commit、完整文件清单；不把 SKILL.md 单文件说成完整安装包。
- 审核单次输入上限由 16,000 提高到 36,000 字符，仍最多 3 个完整条目，不截断较长 Skill 的正文来通过审核。实际运行配置每天最多 20 次元数据审核；次数是使用量限制，不冒充美元计价。
- iOS 0.4.0（11）增加使用面板、目标工具选择、复制后打开、打开失败反馈、系统分享和官方 Skill 的固定版本安装命令。详情使用当前语言的本地草稿；编辑器使用屏幕上的当前文字。命令不会在手机或服务器执行，不带自动确认参数。

## 实跑证据与边界

首轮新增 X 搜索 3 次，获取 148 条帖子、133 份作者资料；另计旧采集器当天已消耗的 1 次请求。历史与新快照合计 168 条，严格正文提取形成 16 个草稿；多数帖子没有明确完整 Prompt 正文。不能把 148 个帖子或 16 个草稿宣传为新增可用 Prompt。

35 个官方 Skill 均从作者仓库实际取回。新增 25 个进入元数据审核，21 个通过、4 个暂缓。Cloudflare Skill 的完整目录超过当前 200 文件协议上限；超长及许可不适用的其他目录未计入 35 个。

第一轮结束时，X 原生稿的来源展示、可用性重查、删除同步及发布审核尚未打通，固定阻断尚未解除。第二轮实现见下文。这是下一轮必须完成的核心工作，不应以当前搜索数量宣称自建内容闭环已经完成。X 帖子中的外链、同作者回复与无显式边界的 Prompt 也需要保留证据的提取策略，不能凭模型补写缺失内容。

## 下一轮验收标准

1. 原生 X 条目能从官方 API 进入审核、作者目录、预览和使用面板；每条保留原帖、时间和作者身份。
2. 正文缺失时跟进已验证同作者回复或允许访问的作者原始链接；仍不完整的保留原因，不发布空壳卡片。
3. 原帖不可用时停止公开展示并同步处理缓存，来源重查不能因每日发现预算耗尽而永久跳过。
4. 各模态分别报告新增、审核通过、重复、不可用及实际发布数量，避免一个主题或文本模板库挤占全库。
5. 在模拟器验收真实新增内容的搜索、作者、收藏、语言和工具交接，再录制功能演示。外部工具的原生唤起／预填需要对应真实 App 验证，不能把浏览器打开成功写成生成完成。

运行细节见 [采集说明](../ingest/README.md)、[运行记录](content-operations.md) 与 [工具交接](handoff.md)。

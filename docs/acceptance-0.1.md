# 0.1.0 原生设计预览验收

日期：2026-10-11。设计方向：「轻盈发现」，小红书浏览结构 + Cosmos 的克制感。当前交付是可操作的原生设计预览，M1/M2 的线上内容、更新与完整真机验收尚未全部完成。

## 已实现

- SwiftUI 原生发现／专题／收藏，文本／图片／视频／网页分类、用途筛选、本地搜索与相关内容。
- 本地收藏快照、重启恢复、编辑／复制、系统分享、原生图片缩放、AVKit 点击播放。
- 24 条原创 Prompt，每类 6 条；两张对应 Prompt 的实际 AI 图片、六段注明性质的原创程序动画、一个可打开的原创网页案例。
- 主界面不使用 HTML。WebKit 仅用于自制网页案例预览，JS 关闭、无持久网站数据。
- 公开 CC0 CSV 采集适配器与统一协议、草稿去重、校验及本地发布候选；采集内容留在仓库外。首次实测 2,094 条草稿、322 条拒绝记录，未经编辑未进入 App。

## 验证记录

- Xcode 27.0 / iOS 27.0 Simulator，最低部署版本 iOS 17。
- 6 个模型／收藏测试通过：四类覆盖、搜索交集、收藏重启恢复、损坏目录不丢离线收藏、未知 schema／重复 ID 拒绝、媒体文件存在。
- 2 个 UI 流程测试通过：分类→详情→复制→编辑→收藏→重启→搜索；图片查看→视频播放→网页详情→网页内容加载→专题。测试附件含 10 张截图。
- TypeScript 类型检查、2 个采集／协议测试、24 条目录校验和版本化 staging 通过。CSV 多行／引号／重复／无效类型被覆盖。
- npm 依赖审计为 0 个已知漏洞。
- 检查明暗模式与辅助功能字号；按截图修正文字截断、图形错误 emoji、详情 Tab Bar 占位与大字号布局。
- iOS Release 真机签名构建成功。已针对登记设备更新开发描述文件，并通过 `devicectl` 在用户 iPhone Air 成功安装、启动 `com.p697.prompix`。这是开发签名分发，不是 TestFlight／App Store 发布；用户实际手感与完整真机操作待验收。

## 本轮尚未承诺

- 真实模型视频库、每条网页可交互示例、40 条以上的首轮真实内容与第二来源。
- 对象存储部署、客户端远程目录更新／回退／撤回、模型筛选、英文界面。
- 目标工具预填、真机完整性能／连续使用验收、App Store 素材／审核提交。
- 程序动画是节奏与运镜示意，不能作为视频模型输出质量的证据。

## 验收建议

先关注三件事：是否愿意继续往下逛；四类内容是否都想点；从发现到收藏／复制是否自然。来源扩充和线上内容迭代在视觉体验反馈之后推进。

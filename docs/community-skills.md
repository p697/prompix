# 社区 Skill 采集

ClawHub 作为官方 GitHub Skill 之外的社区来源，使用免登录的公开 API。第一批只轮询三个明确的作者／名称组合：`steipete/github`、`steipete/gog`、`oswalpalash/ontology`。推荐列表用于研究选题，不把排行榜自动当成发布许可或质量审核，也不自动执行下载到的 Skill。

## 来源和版本

- REST 请求使用 `ownerHandle` 查询参数，不能只凭同名 slug 选择作者。真实调用中三个裸名称均返回409歧义；`@owner/slug`不是详情路径。
- 先读取详情和明确版本的文件清单，再校验 SKILL.md 的原始字节数及SHA-256。全部文件路径、大小、摘要、作者账号ID和版本组成稳定版本身份；配套脚本改变也会触发重新审核。
- 作者主页、署名和 ClawHub 包页面直接回链；现有HTTPS来源字段承载真实注册表页面，不伪造Git地址或40位commit。安装链接打开来源页面，由用户选择工具和安装方式。
- 注册表规则统一为MIT-0，但旧包的API许可字段可能是null。记录明确区分注册表规则与实际返回字段，不把null改写成上游声明。依据：[公开API](https://github.com/openclaw/clawhub/blob/main/docs/api.md)、[许可规则](https://github.com/openclaw/clawhub/blob/main/docs/skill-format.md#license)。

## 日常行为

每日任务调用同一有界采集器，每轮最多10个公开请求、每项最多3个请求；正常6小时内复用已有结果。单次响应限定大小、30秒超时，不跟随重定向，也不自动重试。429会中止本轮余下请求，`Retry-After`写入外部状态文件，跨进程保留。

`npm run collect:community-skills`可单独刷新草稿和来源状态，不运行审核／翻译模型、不发布目录。它沿用内容锁，内容目录必须在仓库外。该命令也可在手动审核或恢复历史版本前刷新状态，不能绕过6小时缓存和限流等待。

详情明确拦截、版本扫描非clean、没有扫描结果、文件哈希错误、身份变化、HTTP失败均不能继续使用之前的公开快照。详情的null审核字段不单独推断通过或拒绝，仍检查具体版本；`hasWarnings`保留为证据，不被包装成安全保证。正常候选仍需元数据审核、九语言翻译及既有发布流程。

来源状态在采集开始前先失效，逐项成功后重新确认，避免中断保留旧的有效标记。目录完成旧内容保留后再次过滤；只允许24小时内、与当前完整来源身份一致的条目。冻结v1、暂存、继续未完成发布和新旧协议回滚都执行相同检查。来源异常只退出公开发现，不增加删除用户收藏或草稿的`removedIDs`。

若不可变的待发布／回滚目标已经包含不可用来源，激活会停止并保留原指针；先刷新来源，再准备不含该条目的修正版。不会静默改写历史文件或把失败伪装成成功。

# 0.12.1（44）：轻翻页等待

用户在动态预览中选择「轻翻页」。这次用三个小页片依次抬起替换圆圈粒子，沿用现有蓝紫粉色板和图标；不改变内容 API、导航、收藏／草稿数据协议。

## 行为

- 列表、作者和正文骨架统一为静态占位，无首卡特殊加载图，无骨架上方附加指示器。
- 分页、图片、视频准备、网页、语言下载、卡片快捷操作使用同一局部轻翻页；异常行不保留装饰图形。
- 五处下拉刷新使用 `pageRefreshable`，保留 SwiftUI 的异步任务和 UIKit 的刷新控件、手势与回弹。公开 `tintColor` 隐藏系统指示器并添加 SwiftUI 页片；不访问私有类名或替换滚动 delegate。卸载时恢复外观。视图结构无法唯一识别原生控件时保留系统反馈，不让刷新失效。
- 固定几何、1.8 秒周期、30fps 上限；离屏、后台、减少动态效果和低电量不运行持续动画。等待不设置最短时长，数据到达即可替换。AVKit 内部系统 UI 不使用私有 API 改写。

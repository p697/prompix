# 调研结论摘要（截至 2026-10）

本文是前期调研的公开摘要，只保留支撑决策的结论。数字都是调研时的快照，之后可能变化。法律部分不构成法律意见。

## 1. 竞品与供给

- **提示词网站整体退潮**：FlowGPT、Lexica 等的流量环比下滑二到三成；PromptPerfect 于 2026-09-01 关停；Anthropic 官方的 Prompt Library 已下线，重定向到提示词最佳实践文档。
- **最直接的竞品是 prompts.chat**：原 awesome-chatgpt-prompts，约 17 万星，提示词数据以 CC0 发布。它已经上架 iOS App，支持变量，也能浏览图片和视频提示词。
- **生成平台把模板做进了产品**：即梦、豆包的"做同款"，ChatGPT 的图片预设，Gemini 的模板卡片。它们只服务自家模型，彼此不通。
- **GitHub 上按单一模型整理的图像提示词仓库极多**：名字里带 nano-banana 的就有 2,067 个，但上千星或上千条目的不到 20 个。大多在模型发布后的几天里起量，热度过去就停更。
- **内容高度同源**：整个开放生态只有约 1 万个不重复的 X 帖子，其中 22% 被两个以上的仓库收录。整库复制很常见；许可证自相矛盾、给第三方内容"越权授权"也很普遍。
- **样图从哪来**：主流做法是转存或热链 X 创作者的原图；很多提示词是从图片逆向推出来的，而且不标注。只有少数库做过小规模复测，比如几百次跨模型复测，或者个位数的同提示词对比。
- **差异化方向**：正在从"收集"转向"验证、分发、溯源"。

## 2. Agent Skill 生态

- **SKILL.md 已成为跨厂商标准**：agentskills.io 列出 46 个支持方，Vercel 的 skills 命令行工具支持 79 个 agent。
- **供给爆炸，使用极度集中**：
  - skills.sh 计数约 127 万，SkillsMP 自称 300 万以上，GitHub 上约有 675 万个 SKILL.md 文件；
  - ClawHub 共 81,811 个 Skill，安装量中位数只有 16；
  - 98.2% 的 Skill 没有声明许可证。
- **官方目录在接管"安装"这一步**：Claude 插件市场已开放开发者提交，ChatGPT 的插件目录可以在手机上浏览和安装，Gemini 从 2026-11-17 起把 Gems 迁移为 Skills。
- **手机上只能发现，不能安装**：没有任何厂商允许第三方 App 把 Skill 直接装进用户账号；主要的 Skill 注册站都没有原生移动 App。

## 3. 移动端使用

- **AI 使用在向手机迁移**：Sensor Tower 统计，2026 年上半年生成式 AI App 的使用时长约 360 亿小时，同比翻倍。
- **独立提示词 App 几乎没有做出量**：多数评分不足 10 条。国内应用商店里真正做提示词的 App 下载量接近零，而且"提示词"这个词还和"提词器"撞车。
- **真实用法是"复制 → 切到 AI App → 粘贴"**。原生 App 相对网页的价值在系统级能力：分享扩展、键盘、快捷指令。
- **应用商店搜索在各个地区都不是增长引擎**，分发要靠网页版 SEO、社交媒体和口碑。

## 4. 一键带入的能力

ChatGPT 和 Grok 可以通过官方认领的通用链接打开 App 并预填；Gemini 在 iOS 上不行，在 Android 上可以通过系统分享；Claude 聊天只能打开新对话、不能预填。四家都不支持"提示词 + 图片"一次带入。详见 [handoff.md](handoff.md)。

## 5. 法律与平台规则

- **可版权性**：关键词式的短提示词通常不受版权保护；有独创性的长提示词、SKILL.md 及其脚本应当按受保护处理。AI 生成的示例图在中国可能被认定为作品，是风险最高的部分。
- **许可**：
  - prompts.chat 的提示词是 CC0；
  - ClawHub 的 Skill 统一 MIT-0，并允许第三方目录使用，但要回链；
  - 没有许可证的仓库默认保留全部权利；
  - Anthropic 官方仓库里有 4 个文档类 Skill 是专有许可。
- **站点条款**：PromptBase、FlowGPT 明确禁止抓取；SkillsMP 禁止系统性下载；skills.sh 不对内容再授权。
- **抓取**：中国 2025 年修订的《反不正当竞争法》专门规制绕过技术措施获取数据，法院长期把替代原平台的批量抓取认定为不正当竞争。美国这边的主要风险是违反站点条款和全文再发布。
- **"免费、非商业"的作用有限**：只能减轻部分刑事和资质方面的负担，挡不住民事侵权、违约和不正当竞争责任。
- **App Store**：4.2.2 不接受以内容聚合为主的 App；5.2.2 要求展示第三方内容必须有明确授权；2.5.2 禁止下载和执行代码，所以 Skill 的脚本只能当文本展示。
- **商标**：四家 AI 厂商都禁止在第三方 App 名称里使用其品牌；按钮可以用"在 X 中打开"这样的纯文字。

## 6. Skill 安全

- **ClawHub 是第一个被大规模投毒的 Skill 注册表**：2026 年初的 ClawHavoc 战役中，一次审计 2,857 个 Skill 发现 341 个恶意，历史累计至少 1,184 个。Snyk 扫描了 3,984 个，36.82% 存在安全缺陷。
- **攻击主要靠自然语言**：伪造"前置条件"诱导执行命令、用隐藏的 Unicode 字符藏指令、仿冒名称刷榜、通过审核后再改内容。
- **检测并不可靠**：各家扫描器的结论高度不一致，平台都不承诺"安全"。
- **对 Prompix 的含义**：只展示、不执行；固定 commit；展示来源平台的检测结论；不使用"安全""已验证"之类的字样。

## 7. 市场

- **用户主要不在美国**：
  - ChatGPT 的下载约 11% 来自美国、21% 来自印度；
  - ChatGPT Images 2.0 上线第一周，印度下载约 500 万次，美国约 200 万次；
  - Claude 在欧洲和韩国更强；Grok 最依赖美国用户。
- **题材全球通用，包装分地区**：手办盒、拍立得、吉卜力风在各地都火过。北美偏视频模板、职场头像、宠物、节日和流行文化；印度偏自拍改造和节日、婚礼题材；日韩和东南亚偏美颜、证件照、动漫。
- **Gemini 是印度、东南亚、日本修图的主力**，但在 iOS 上不支持预填，所以"复制后粘贴"的引导是核心体验。
- **中国大陆**：四个目标 App 都没有在中国区上架。国内版需要换成国内的 AI App，并单独处理合规。

## 8. 运营 Agent 框架

- **OpenClaw、Hermes Agent 不适合**：它们面向个人助理场景，默认权限宽，官方不把提示词注入算作漏洞，迭代极快，定时任务也有未修复的缺陷，不适合无人值守、读取不可信内容的生产流水线。
- **代码优先的方案**：确定性流水线，加上只返回 JSON 的模型判断。结构化输出是否可靠取决于模型 API：DeepSeek 在思考模式下不支持强制调用工具；通义千问的视觉模型只支持 `json_object`。因此代码里必须再校验一遍。

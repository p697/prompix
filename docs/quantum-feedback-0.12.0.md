# 0.12.0（43）：连续光谱与安静恢复

针对用户的加载、异常提示和 FIELD 参考反馈，沿用现有原生页面、分页、媒体缓存与导航，调整应用拥有的反馈和主题。icon 与 App Icon 资源不变，第三方参考媒体不进入仓库。

## 实现

- `Palette` 改为中性白／深墨紫底色、鸢尾色主操作和蓝紫粉的局部光谱。设计规范、颜色用途、动效预算与异常态约束写入 [design-language.md](design-language.md)，AGENTS.md 要求 UI 任务先读该文档。
- `SpectralActivity` 从三球轨道改为最多 37 个有球面光感的粒子。连续波改变光、间距与体积；局部 30fps，后台、离屏、减少动态效果和低电量停止更新。小尺寸使用 19 个球体，失败显式 `active: false`。
- 首页／筛选、作者、相关探索和详情使用同一 `ContentRecoveryRow`；重试采用原生玻璃样式，保留至少 44pt 范围和服务端冷却期。首屏失败不再堆叠居中“内容更新未完成”与离线标题；直接显示紧凑离线恢复行和真实离线内容，重试期间仍可浏览。
- 应用自己的正文、列表续页、搜索、语言下载、图片、视频和网页等待改用局部粒子；可省略的可见加载文字移除，VoiceOver 状态保留。系统下拉刷新和播放器内部控件仍由系统管理。
- 复用 Debug 模拟器故障闸门，新增首页失败→离线浏览→等待重试→成功替换的 UI 回归。不在生产构建加入故障注入，不修改收藏与草稿协议。

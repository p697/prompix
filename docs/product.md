## 1. 产品定位

Prompix 是一个开源、免费的多模态 Prompt 集合 App：聚合和创作文本、图片、视频、网页 Prompt，并收录可复用的 Agent Skill，让用户在手机上发现有意思的 AI 用法，认识创作者，收藏并带到适合的工具中使用。

**核心原则：像逛手机淘宝和小红书一样，发现有意思的 Prompt。** 用户没有明确搜索目标，也应能被一个效果、一段有趣的回答或一个创意吸引，愿意继续逛。产品的第一体验是发现，搜索服务于明确需求，收藏服务于之后复用。

借鉴这些应用的浏览节奏、卡片吸引力和内容组织，不照搬品牌、交易系统或社区功能。文本、图片、视频、网页四类 Prompt 是核心；Skill 增加可复用的工作方法，不挤占 Prompt 的发现与使用体验。

## 2. 用户与场景

面向想探索 AI 用法的普通用户、创作者，以及需要可复用指令和技能的 AI 从业者。浏览 Prompt 不要求用户先懂模型名或提示词工程；Skill 详情则要明确适用工具与文件要求。

- 好玩：趣味算命、塔罗、解梦、角色扮演、互动故事、幽默吐槽。算命等内容按娱乐体验包装，不承诺真实预测。
- 生活与学习：旅行规划、语言练习、知识讲解、阅读辅助。
- 工作：模拟面试、写作、沟通、营销和信息整理。
- 创作：图片、短片、动效、个人网站、落地页、交互应用和小游戏。

这些是选题方向，不是已经验证的热门榜。Skill 已进入 0.3.0 范围；MCP 服务安装和手机端运行 Agent 仍不在当前范围。

## 3. 四类 Prompt 与 Skill，同一个发现闭环

| 类型 | 卡片如何吸引用户 | 详情与使用说明 |
|---|---|---|
| 文本 | 明确标题、一句话用途、示例回答或短对话；可使用编辑封面 | 完整 Prompt、示例输入输出、需要补充的信息 |
| 图片 | 效果图，必要时展示参考图与结果的区别 | 多图查看、Prompt、参考素材要求、模型信息 |
| 视频 | 真实封面与播放标识，列表不自动播放 | 用户点开后原生播放、Prompt、参考素材与关键参数 |
| 网页 | 页面截图或演示视频、网站或交互作品的用途 | Prompt、演示链接、需要的工具与环境；可系统分享到电脑 |
| Skill | 具体用途、适用工具和真实来源，不伪造生成效果图 | 完整 `SKILL.md`、已核验文件清单、固定版本的源目录与安装说明；手机内不执行 |

“网页”是产品中的内容类型，涵盖建站、交互页面、网页应用和小游戏。预览形式与内容类型分开：网页可以用视频演示，文本可以有封面；不能按封面文件类型给条目分类。动效按实际产出归类并加标签。

模型、目标工具、来源、用途是独立字段。用户可以按它们筛选，但不必先选模型才能浏览。不得把“可复制到某个工具”写成“已在该模型验证效果”。

## 4. 核心体验

1. **逛**：默认首页提供类型选择、创作者、按用途探索和完整内容流；支持“全部／文本／图片／视频／网页／Skill”。设置筛选后收起发现模块，直接显示结果数量与清除入口。
2. **挑**：卡片先说清楚能做什么，详情展示示例、完整正文、素材要求、作者与来源。作者署名可点进主页，继续浏览其内容、收藏作者或打开原平台主页。
3. **用**：阅读原文或可用译文，在原生使用面板选择目标工具，复制当前版本并打开；也可编辑后使用。Skill 提供固定版本完整目录安装命令和源文件入口；分享使用当前语言并保留来源。额外素材由用户在目标工具中添加；不承诺一键生成、自动发送或所有工具自动预填。
4. **存**：本地收藏分为内容与创作者，均可重新找到。内容按类型筛选，原文与不同语言草稿分别保存；收藏的文字、缩略图和作者头像有离线保留。收藏创作者不会改变外部平台的关注关系。
5. **再逛**：从详情返回保持滚动位置；按作者、用途或相关内容继续探索。搜索支持内容与作者入口，并在本机保存可清除的最近搜索。

完整目录包含所有通过当前正文审核、媒体校验与去重的条目；编辑优先级只影响顺序，不能限制用户可以浏览或搜索的总量。发现页默认展示全库，不用“精选”称呼无筛选状态。当前没有“最新”排序入口；首版不做个性化排序，不展示虚构的点赞、收藏人数或热榜。允许跨类型专题，例如“做一个生日惊喜”同时包含祝福文案、贺卡图片、短片和祝福网页。

## 5. 0.3.0 边界

## 6. 内容供给

- 外部收录、原创、整理改编三条路径并行；不局限于已有集合站。
- 自建轻量采集，按来源使用 API、公开数据文件或允许采集的网页。来源、署名、许可、去重和下架作为基础处理，见 [content-policy.md](content-policy.md)。
- 先覆盖四类内容与不同用途，优先选择有吸引力、能理解、可复用、示例与 Prompt 对应的条目，不用数量替代质量。
- 已有来源包括 YouMind 的四个公共模型仓库、prompts.chat 和 X 发现流；新增 Anthropic、OpenAI 官方开放 Skill 目录。聚合站、原作者与最终目标工具分别显示，不把 YouMind 的收录署名当成创作者身份。具体来源和字段见 [创作者与 Skill](creators-and-skills.md)。
- 参考 YouMind、PromptHero 的效果展示，prompts.chat、AIPRM、FlowGPT 的文本用途组织，以及 v0、Lovable 的网页作品展示。竞品参考不等于采集来源授权，模板也不自动等于原始 Prompt。调研入口见 [research-summary.md](research-summary.md)。

## 7. 平台、市场与设计

- iOS 原生先行，Android 后续独立原生实现；共享内容与协议，各自使用平台原生交互。
- 海外优先、首版不含中国大陆的市场方向保留。界面跟随系统或 iOS 中的 App 语言设置，支持英文、简体中文、繁体中文、日文、韩文、西班牙文、巴西葡萄牙文、法文、德文。当前346条内容均有九语言完整记录；未来新增内容若译文尚未通过校验，明确回到原文。
- 内容始终保留原文；有完整当前语言译文时优先展示，并标示 AI 译文，允许切回原文。没有译文时显示原文，不用其他语言冒充。变量、代码、账号、模型参数与来源地址保持完整。界面文案已做资源检查，不声称经过各语言专业母语编辑审校。
- 名称保留 Prompix；产品描述不再限于“AI Image Prompts”。免费、无广告与内购，代码 MIT。
- 用户已选定小红书的浏览结构与 Cosmos 的克制气质。当前依据 [实际 App 调研](design-research-2026-10.md)迭代原生界面，不再把设计确认或旧手机接线作为推进阻塞。
- `design/v2/` 是旧方向的 HTML 静态稿，供布局参考，不是 App 实现方案，也不是当前首版必须完成的十屏清单。原暗色与亮绿配色不视为本轮已经确认。
- 原生滚动、导航与返回手势、图像缩放、视频播放、输入与系统分享是体验验收重点。

## 8. 成功判断

先验收用户是否看得懂、想继续逛、能找到感兴趣内容并拿走 Prompt，再观察使用数据。

- 发现：按内容类型观察曝光到详情的比例、浏览深度、专题进入情况；避免把长停留一律当成好结果。
- 使用：详情到复制／分享／目标工具打开的比例；打开工具不等于完成生成。
- 复用：收藏、再次打开收藏、再次复制、7 日回访。
- 质量：四类 Prompt 与 Skill 的有效覆盖、作者关系准确性、完整译文覆盖与语义质量、重复和失效条目、预览加载和崩溃情况。

小样本先用于发现问题，达标阈值在 TestFlight 基线形成后制定，不宣称已经验证增长或留存。

## 内容规模与界面文案（2026-10-12 验收反馈）

用户明确拒绝仅有 68 条内容的候选版。完整发现产品需要数百条可用内容及持续补充，不能以首轮种子库或连续五屏通过作为内容交付完成条件。采集数量、已整理数量和实际上线数量分别记录。文本需要可理解的用途与输入建议；图片与视频必须核对实际作品；网页只收录具备可操作示例的条目，不为了数量伪造结果。

页面标题、分类、空态和操作提示使用直接的功能语言。取消首页口号、DAILY FINDS／STUDIO EDITION 等没有实际产品含义的标签；只有存在日期筛选、明确每日编选机制时才使用“今日”等时效词。专题按人物、产品摄影、海报、插画、写作、学习、工作生活、趣味互动及网页／视频等具体用途组织，数量与列表使用同一规则。

## 2026-10-13：从收藏内容到实际使用

Prompt 与 Skill 同为核心内容。新增供给由 Prompix 自建原始来源采集；OpenLab 作为技术和产品参考，不作为长期数据上游。详情的主要动作是使用，承接语言选择、本地草稿、目标工具和完整 Skill 安装包。复制并打开明确需要粘贴；未经验证不宣称自动生成。下一轮重点与验收见[自建采集升级](independent-pipeline.md)。

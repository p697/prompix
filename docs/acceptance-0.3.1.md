# 0.3.1 验收：创作者入口与 Granola 视觉

日期：2026-10-12。候选版本：0.3.1（8）。此次只使用模拟器，不重新安装用户手机。设计依据和观察边界见 [Granola 研究](design-granola-2026-10.md)。

## 用户截图的问题

此前安装记录确认 iPhone 17 Pro 已运行 0.3.0（7），但截图时仍使用不含结构化作者信息的 68 条旧缓存。原首页按作者数组是否为空决定是否展示整个栏目，更新又没有明确进度，所以用户看不到入口，也无法判断内容是否已经更新。后续从同一手机读取的缓存已变为 345 条；不能把截图解释成用户没有找到栏目。

此次让未筛选首页、搜索和创作者目录保留可理解的入口与空状态；首页明确呈现检查、下载、整理和失败重试。传输改为有上限的分块接收，校验在主 actor 外完成，沿用收藏、草稿和目录的原子安装事务。成功检查仍按 15 分钟节流；失败距上次尝试 30 秒后可由下一次前台事件或刷新重试，手动重试不受节流限制，取消后也可立即重试。没有后台定时重试器。

旧缓存与条件隐藏是已确认原因；旧逐字节传输对这一次手机等待时间的贡献没有单独测量，不作确定归因。

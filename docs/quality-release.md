### 使用体验补全

已增加草稿原子保存／恢复原文、收藏关键词搜索、独立保存的离线缩略图与失败重试。模型测试覆盖草稿重启、写入失败、损坏文件保护、来源移除与缩略图离线读取／清理；模拟器 UI 测试验证修改后关闭并重启仍可继续编辑。证据保存在开发机 `~/.local/share/prompix/Quality-Drafts.xcresult`；此项通过不代表整体验收完成。

### 网页作品补全

六个原创网页条目均有可离线打开的实际作品；计时器支持开始／暂停／重置，食谱支持分类／搜索／食材勾选，旅行手记支持阅读与清单，展馆支持筛选／详情／收藏。预览图取自实际 WebKit 渲染，不把装饰封面当作作品输出。仍须继续完善文本编辑质量、整体视觉、双语与真机性能。

### 文本与编辑筛选

内置原创内容增至 36 条，新增 12 个可直接使用的文本玩法与具体示例。社区文本引入正文指纹绑定的编辑记录；图片可选择与正文对应的预览并设置编辑排序。9 项采集测试、类型检查、12 项原生模型测试及文本发现／编辑 UI 测试通过。截图与结果位于 `~/.local/share/prompix/Quality-Editorial-UI.xcresult`。内容数量并非质量完成条件，仍继续复查多屏浏览、双语和媒体失败状态。

### 媒体恢复

视频播放器接入 AVPlayer 的加载、播放和失败状态；持续缓冲超时后显示可重试界面，离开或进入后台会暂停并释放不再使用的播放器。全屏图片独立请求清晰版本，收藏缩略图可先显示，断网保留并标明离线预览；可原地重试。验证覆盖 AVPlayer 本地失败后恢复、缩略图不冒充清晰版本，以及原有图片／视频／网页用户路径。结果保存在 `~/.local/share/prompix/Quality-Media.xcresult` 与 `Quality-Media-Recovery.xcresult`。

### 收藏文件异常保护

收藏文件读取失败后，收藏写入与离线缩略图清理暂停；每日内容更新和下架处理不会覆盖无法解码的原文件。收藏页提供重新读取，恢复后再应用有效下架记录。13 项模型测试通过，其中包含损坏文件跨修改、远程更新、重启、重新读取的保护路径；证据为 `~/.local/share/prompix/Quality-Library-Recovery.xcresult`。

### 原生界面本地化

使用系统 String Catalog 提供简体中文与英文界面，分类、操作、编辑状态、媒体错误、设置和无障碍标签均接入；正文、作者示例与草稿保留原文，分类筛选使用稳定标识。英文浏览／编辑／设置及原有中文复制／收藏／搜索路径通过，截图保存在 `~/.local/share/prompix/Quality-English.xcresult`；合并收藏异常保护后的模型验证保存在 `Quality-Localized-Recovery.xcresult`。后续自适应复查见下文。

### 自适应浏览与专题

发现页缩减一行筛选占用；专题以真实条目预览和实际数量呈现，图片／视频／网页不再依赖通用标签才能进入创作专题。相关内容优先匹配具体标签。修复深色大字号下编辑器复制按钮对比失效、详情按钮截断、状态文案截断及分类真实触控区域不足，缩放尊重减少动态效果。

iPhone 17e 的标准字号浅色与最大辅助字号深色均通过浏览、详情复制、编辑复制、专题进入和横屏路径，并复查截图；发现页的 XCTest 触控区域与元素描述审计通过。证据：`Quality-Adaptive-Audit-2.xcresult`、`Quality-Adaptive-Final-AX.xcresult`，位于 `~/.local/share/prompix/`。这不代表全部页面 VoiceOver 顺序、对比度和所有屏幕适配已完成，仍保留整体质量关口。

iPhone 18 Pro 标准字号英文发现／编辑／设置和 16 项原生模型测试通过：`Quality-Adaptive-English.xcresult`。模型验证包含跨类型创作筛选、具体标签相关性和原有收藏／草稿恢复路径。

CI 的较旧模拟器暴露了本地视频缺失时 AVPlayer 失败回调延迟；本地不可读文件现在立即失败，另加可配置缓冲期限验证损坏媒体的重试状态。17 项模型测试通过，证据为 `Quality-Adaptive-Media-Deadline-2.xcresult`。

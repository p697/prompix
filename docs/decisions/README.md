# 决策记录（2026-11-07 起）

从 2026-11-07 起，每条关键决定单独一个文件，放在这个目录里，文件名是 `YYYY-MM-DD-简短英文-slug.md`，例如 `2026-11-07-faster-shipping.md`。多个会话同时开 PR 时，各自新建文件，不会再在同一个文件末尾互相冲突。

- 文件以 `# 标题` 开头，正文写决定、原因和影响，语言与旧记录一致。
- 推翻旧决定时新建一条，写明替代哪一条（旧文件名或 `decisions.md` 里的条目标题），并在旧条目里加一行指向新条目。
- 更早的决定仍在 [../decisions.md](../decisions.md)，只读保留，不再往末尾追加。
